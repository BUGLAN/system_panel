# 25 · 表情 · 动作 · 预设总表

> 宿主 2026-10-11 定义：**预设 = 动作 × 表情 的组合** —— 动作和表情是两个自由度，
> 组合起来才是"她演的那一下"。本文是这三样东西的**总表**：
> 预设（命名组合）、动作组（资源）、表情（资源）。
>
> 配套：`docs/24-待机与动作表情绑定清单.md`（哪个时刻用哪条预设）。

## 0 三种资源，一次看清

| 资源 | 数量 | 是什么 | 真源 |
|---|---|---|---|
| **预设** | **47** 条 | `动作组 + 表情` 的**命名组合**（如「亮相」= `kime` + `exp_kime01`） | `app/lib/stage/perf_presets.dart` |
| 动作组 | **18** 组 | 模型自带的动作分组（组内 1~6 个 L/C/R 变体，代码随机取）；= 17 个语义组 + `Idle` 别名 | `sakiko.model3.json` → `Live2DStage.motionGroups` + `baseGroup` |
| 表情 | **32** 个 | 模型自带 28 个 + 我们合成 4 个（闭眼/睡/醒） | `sakiko.model3.json` → `Live2DStage.expressions` |

⚠️ **不能新增动作或表情文件**（模型侧资产、版权红线、要重导 moc3）——
**新增"预设"才是唯一能扩展的维度**，而且只是往 `PerfPresets.all` 里加**一行**（见 §4）。
⚠️ `param()` 逐参数写法单帧即被覆写（STAGE-OPTIONS 坑），所以闭眼/睡/醒只能靠那 4 个合成表情。

## 4 组合规则（新增一条预设要做什么）

1. 在 `app/lib/stage/perf_presets.dart` 的 `PerfPresets.all` 里加**一行**：

   ```dart
   PerfPreset('sob', '抽泣', PerfFamily.extra, 'cry', 'exp_cry01', '连败一档'),
   ```

   （id / 中文名 / 族 / 动作组 / 表情 / 用在哪 / 可选 `priority:`）
2. 只想"能试"：到此为止 —— 调试台立刻能看到它。
   要"接进流程"：在 `main.dart` 对应时刻调 `_stagePort?.preset(p)`，
   或写进 `StageBridges` 的 `verbFace` / `idlePool` / `emotionAct`。
3. 跑 `flutter test test/stage_port_test.dart`（核对：动作组与表情必须真实存在、
   id 不重复、优先级 1~3、按族取不丢条目）。
4. 本文的 §1 由代码生成（§6 有命令），改完重新生成，别手抄。

**红线**：① 只能从 18 组 / 32 表情里挑；② 同一拍只演一件事（不许叠两个动作）；
③ 待机预设必须 priority 1（不许打断正在看的表演）；④ 借出去的表情 3 秒后
归还当前情绪（`Live2DStageHandle`）。

## 5 调试台（PERF LAB · 宿主专用）

**入口**：设置页（底栏「系统」投影面板）→ 最下面一行「表演调试台 → 打开」。

**形态**：贴底半屏面板，**上面半屏留给她** —— 点一下就能看反应。

| 页签 | 内容 | 点一下会发生什么 |
|---|---|---|
| 预设 | 47 条，按族分组（id + 中文名 + 动作+表情 + 用在哪） | 整条演（动作 + 表情，按它自己的优先级） |
| 动作 | 18 个动作组（含变体数） | 随机播一个变体，**不动表情**（纯看动作） |
| 表情 | 32 个（下标 + 现在被谁用） | 只换脸，不动动作 |

外加四个快捷键：**睡着 / 惊醒 / 回情绪 / 随机待机**（从默认池随机抽一条）。

⚠️ 调试台是**设施**不是产品界面：不进底栏、不写存档、不参与发布/结算；
「收起」或点幕布关掉，回到原页面。

## 6 落点与校验

| 想改什么 | 改哪里 |
|---|---|
| 预设清单（名字/组合/优先级/用在哪） | `app/lib/stage/perf_presets.dart` |
| 情绪→表情 / 动词→表情 / 待机池 / 情绪→动作 | `app/lib/stage/stage_port.dart`（`emoExp`/`verbFace`/`idlePool`/`emotionAct`） |
| 某指令时刻用哪条 | `app/lib/main.dart` 的 `_stagePort?.preset(...)` / `perf(...)` / `act(...)` |
| 调试台界面 / 入口 | `app/lib/widgets/perf_debug.dart` / `sheet.dart`（设置页那一行）+ `main.dart`（叠层） |

按族取不丢条目、动作组总表 = 17 语义组 + `Idle`；另有桥接表 ↔ `model3.json`
一致性核对（有产物时）。
