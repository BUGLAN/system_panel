## 2 · 拆解：roguelike 的「几选一」为什么上瘾

十条原理，每条都落到本 App 的一个具体决定上：

| # | 原理 | 游戏里的样子 | 落到本 App |
|---|---|---|---|
| 1 | **三是魔法数** | 杀戮尖塔卡牌奖励 3 张；哈迪斯祝福 3 个（特权时 4 个） | 默认 3 张；4 张必须是「特权」（天赋「好奇心」）；超过 4 个一律改「牌册」浏览 |
| 2 | **种类不同，而不是数值不同** | 哈迪斯三位神给三个流派，不是同一招的三个数值 | 委托三张固定三种身份：**补短 / 贴主线 / 随缘**——这正是 `pickDailies` 现在在后台替你挑单的策略（docs/18 §2.2），只是摊到桌面上 |
| 3 | **先期待，后揭晓** | 小丑牌开包；抽卡时流星颜色先透露稀有度 | 牌背先到；揭示前 120ms 牌背四边「预辉」透露稀有度；**最稀有的最后翻** |
| 4 | **信息给到「能做决定」为止** | 杀戮尖塔卡面写全效果；《王权》拖动卡片时会受影响的数值点亮起 | 领位全开、侧牌摘要、长按审视翻到背面看明细与历史 |
| 5 | **给随机加把手** | 小丑牌刷新商店；吸血鬼幸存者重抽 / 放逐 / 跳过 | 换单券 = 重抽；「换一个」= 下拉降档；「等会儿」= 扣下（§9） |
| 6 | **放弃也是一种选择** | 杀戮尖塔「跳过」+ 歌唱碗；小丑牌跳过盲注拿标签 | 每张牌桌都有「不选」的出口，而且出口**要么有代价、要么有补偿**，不是白给 |
| 7 | **选择要留下痕迹** | 杀戮尖塔选中的牌飞进牌组；哈迪斯祝福图标挂上 HUD | 选中的牌飞向它的「归宿」；没选的也有「去处」（§3.3） |
| 8 | **高频选择必须快** | 杀戮尖塔战后选牌 2~3 秒选完 | 四级仪式 + 点按跳过；日常委托从「叮」到可选 ≤0.8s（对齐「发布 ≤800ms」） |
| 9 | **角色在场** | 哈迪斯神祇递祝福时开口；《命运之手》的发牌人一边发一边评 | **她是发牌人**：视线跟着领位走、每张牌有她的批注、你选完她回嘴 |
| 10 | **风险回报摆在明面** | 哈迪斯混沌门（先吃诅咒后拿祝福）；杀戮尖塔开局的涅奥交换 | 押注 / 契约（机制层与狂想区，可选） |

**三条反面教训**（同样要写进规格）：

- **选择疲劳**：一天被要求「选」太多次，选择就变成了家务。→ 设计目标：每日 A 级以上抉择 ≤4 次（目标，不是硬上限）；每张牌桌都有一个「默认路径」可以一下过。
- **假选择**：三张牌其实差不多，玩家很快看穿。→ 三张必须种类不同（原理 2），并用本地记账盯「位次分布」（§20.4）。
- **仪式疲劳**：每天看同一段 3 秒动画。→ 高频压到 ≤0.8s、全程可点按跳过、同日第二次起自动播简版（对齐「同日重复只播简版」）。

## 3 · 世界观：抉择协议

### 3.1 名字与开场白

- 协议名：**抉择协议 · PICK PROTOCOL**。系统流小说里「叮！请宿主三选一」本就是母题，我们把它做成 App 的一条底层协议。
- 开场白统一句式：**「叮。请宿主 X 选一。」**（X = 二 / 三 / 四）。S 级仪式用「叮！」——全 App 唯一允许出现「！」的地方（DESIGN.md §7）。

### 3.2 隐喻：她发牌，你落子

- 牌从**她胸口的投射光束**里出来（锚点 `StageAnchors.chest` = (195, 375.67)，与 24 号 S18「从她胸口打出的光束」同源）。
- 你选中的牌，回到「你这边」（执行台 / 主线环 / 背包 / 名牌）；没选的，回到「她那边」（袖中 / 熄灭 / 燃尽）。
- 原型有一句设计原话值得原样继承：**「按住指纹 = 接下；别的选择都要对她说出口」**（`flows.js:249` 注释）——所以「出口」永远写成一句宿主对她说的话（「等会儿」「今天算了。」），不是冷冰冰的「取消」。

### 3.3 牌的来路与去处

| 牌种 | 从哪来 | 选中后去哪 | 没选的去哪 |
|---|---|---|---|
| 委托 | 胸口光束 | 压指纹印 → 飞向执行台（日常）/ 飞上对应主线环（主线） | 翻回牌背，沿光束收回**她袖中**（当日可再换） |
| 物件 | 背包 | 化成光粒钻进当前委托，委托牌角上多一枚印 | 原位落回 |
| 方向 | 她那句台词的句尾 | 化成你的一句话（字幕层「宿主 › 再来一单。」） | 淡出熄灭 |
| 命途 | 光束（S 级：她做 `present` 亮相动作） | 展开成主线轨，环挂到她头顶 | 碎成光点，不可再见 |
| 天赋 | 经验条顶端掉落 | 嵌进档案页天赋槽 | 翻面亮出「你错过了什么」0.6s，然后燃尽 |
| 称号 | 牌册 | 飞向档案头部名牌，名字被激光重刻 | 留在牌册 |
| 残局 | 黯场中央 | 成为补救单 | 熄灭 |
| 技能 | 聊天输入框上沿 | 化成一条〔工具〕回执滑进对话流 | 收回 |
| 设定 | 设置行 | 原位亮起 | — |

### 3.4 牌背、牌库与选择权

- **牌背**：系统徽记（六边形）+ 32px 网格 + 一道扫描线 + 底部 mono 编号 `NO.0427`——**全局第几次发牌**。你的选择史一张张累积在牌背上；这个编号也是「退出重进不换牌」的锚（§9.2）。
- **牌库**：她手里那副牌 = 所有可能选项的来源（委托池、道具、称号、天赋……）。你看不见全貌，只能看见她发出来的；见过的牌可以在「图鉴」里回看（§16）。
- **选择权是挣来的**（机制层 M1）：前 10 单由她指派（现状，对齐 05 号「前 10 任务必胜」）；累计完成第 10 单那一刻：**「叮！权限提升：宿主获得选择权。」**——一次性的 S 级仪式，把「教学」嵌进成长里。

## 4 · 全场景盘点：App 里所有「要你选」的地方

### 4.1 仪式分级

| 级 | 定义 | 频率 | 叮 → 可选 | 落定手势 |
|---|---|---|---|---|
| **S · 大仪式** | 改变主线或人生走向 | ≤1 次 / 周 | ≤2.0s（对齐「升级 ≤2s」） | 按住指纹区 0.9s |
| **A · 正式** | 消耗资源或当日不可逆 | 1~4 次 / 天 | ≤0.8s（对齐「发布 ≤800ms」） | 按住 0.5s 或 0.9s |
| **B · 轻快** | 几乎无代价、可逆 | 随时 | ≤0.35s | 点领位 |
| **C · 微牌** | 偏好设置 | 很少 | 即时（≤0.15s） | 点即生效 |
| **失败档** | 认输与补救 | — | ≤0.3s，只淡入 | 按住 1.2s（认输）/ 0.6s（接补救） |

## 6 · 七种牌阵

七种布局共享同一条手感法则（23 §3）：**任一时刻恰有一个领位，领位抬起，邻位按距离双向让位**。区别只在「怎么摆、怎么让」。

### 6.1 扇 · 旗舰牌阵

- **用在**：委托三选一、命途、天赋、技能（迷你版）。
- **张数**：2~4，默认 3。
- **几何**（领位中心 x = 195；牌桌落在屏幕下三分之一，她在上方）：

| 位 | 缩放 | 横移 | 纵移 | 旋转 | 不透明 | 层级 |
|---|---|---|---|---|---|---|
| 领位 | 1.00 | 0 | −16 | 0° | 1.0 | 最上 |
| ±1 | .82 | ±104 | +18 | ∓6°（向外倾） | .62 | 中 |
| ±2（仅 4 张） | .70 | ±178（露半张） | +40 | ∓11° | .40 | 底 |

- **转轴**在牌底中心——像手里捏着一把牌，而不是在桌上平铺。侧牌外侧上角可以出屏（露边是质感），但侧牌的可点区（牌心 60%）必须完整在屏内。
- **换领位**：整组沿弧滑动，弹簧用真源 `Spring(k: 120, ζ: .9)`（`stage/spring.dart`；25 号 G3 指出它现在没人用，扇阵正好是它的第一个正式用户）。

```
+------------------------------------------+
|=================== EXP ==================|
|                 ( SHE )                  |
|        >> DING. PICK ONE OF THREE.       |
|                    :  <- beam            |
|   +--------+  +-----------+  +--------+  |
|   |QUEST  D|  |QUEST     B|  |QUEST  E|  |
|   | title  |  |   GLYPH   |  | title  |  |
|   | 6 . 5  |  |  TITLE    |  | 1 . 5  |  |
|   +--------+  |  rule     |  +--------+  |
|   -6deg .82   |  loot     |   +6deg .82  |
|               |  >> note  |              |
|               |[  HOLD   ]|        [?]   |
|               +-----------+              |
|  [SWAP x2]        .  o  .       [LATER]  |
+------------------------------------------+
```

左「补短」· 中「贴主线」（领位）· 右「随缘」；`[?]` = 她的暗牌「随你」；底排 = 重抽（换单券）· 位次点 · 等会儿。

### 6.2 台 · 物件台（= 23 甲，原样收编）

- **用在**：使用道具；补给（货架变体）。
- **几何**：以 `item_rail.dart` 顶部常量区现值为准（卡 86×112、侧卡缩放 .88、名称 15px → 等效 13.2px、侧卡向外旋开 ±4° 并压暗）。
- **货架变体**：四张物件牌挂在一条发光挂轨上，牌下吊六边金币价签；买不起 = 灰 + 价签红描边 + 小锁。

### 6.3 轨 · 铭牌轨（= 23 乙，原样收编）

- **用在**：回应、访谈答案、所有对白选择。
- **几何**：沿用 23 乙（横版斜切薄牌 268×58；领位左对齐 + 抬起 −8 + 左侧 3px 青竖条；其余向右阶梯缩进 14px × 序数、下沉 6、压暗 .5；**不缩放**，保证 15.5px 正文可读）。
- **竖排变体**（访谈答案可能两行）：300×64 竖叠，间距 10；领位向左探出 12px + 青竖条，其余不动——这是 DESIGN.md 允许的「单列堆叠」。

### 6.4 对 · 单牌对决

- **用在**：主线环（锁定单牌）、认输书、补救、她的提议牌、销毁协议。
- **形态**：一张 L 牌居中 + **一个重手势** + **一个轻出口**：
  - 重手势 = 按住指纹区（时长按 §8.2）；
  - 轻出口 = 牌下一枚铭牌（「等会儿」「今天算了。」「算了，不换」）。
- **提议牌**额外允许《王权》式拖动：右拖接受、左拖不换；拖过 96px 或甩动超阈值即判定，未过阈值弹簧回位；拖动中牌对应一侧的边缘字（「换」/「不换」）逐渐亮起。

### 6.5 暗 · 扣着的牌

- **用在**：首目标三环揭晓（只开不选）、见面礼（可选的盲选变体）、她的暗牌「随你」、狂想区的运势牌。

## 7 · 一次抉择的六拍

### 7.1 状态机

```
SUMMON -> DEAL -> REVEAL -> BROWSE <-> INSPECT
   |                        ^  |
   +--- tap anywhere: skip -+  +--> (A/S) ARMED --release early--> BROWSE
                               |            |
                               |            v
                               |         COMMIT -> AFTERMATH -> EXIT
                               |
                               +--> (B/C) COMMIT -> AFTERMATH -> EXIT
                               |
                               +--> exit plate / back key --> FOLD -> EXIT
```

- 召唤 → 揭示：整桌 `IgnorePointer`，只留一层「点按跳过」。
- 端详：唯一允许自由停留的状态；在这里停多久都不会有惩罚。
- 待发：只有 A/S 级才有——按下指纹区那一刻进入，松手按退回时长回到端详。
- 落定：瞬间锁桌（沿用 `choices.dart` 的 `_locked` 语义：一下 = 一声 + 一震）。

### 7.2 A 级逐帧：委托三选一（叮 → 可选 ≤ 800ms）

### 7.3 S 级逐帧：升级 · 权限提升（叮 → 可选 ≤ 2.0s）

| t (ms) | 事件 |
|---|---|
| 0 | 经验条跨级编排（涨满 360 → 白闪 → 归零，现有 `hud.dart` 参数）；按 25 号批次一，这段应发生在结算页里 |

### 7.4 B 级：回应（≤ 350ms）

铭牌从她那句台词的句尾滑出（240ms `kOut`，错峰 0 / 60ms）→ 领位 → 可选。点领位 = 落定：牌向左滑出（−28px + 淡出）+ `choose`（23 乙已实现）。

### 7.5 失败档：补救（≤ 300ms）

不翻面、不飞行、不粒子、不白闪；残局牌原位淡入并上浮 12px（300ms）；亮度为成功态的 1/3；`fail` 音已在失败流里响过，这里**不再发声**。落定 = 按住 0.6s，牌面只有一道细青线填满，没有压印，牌直接变成补救单那一行。

### 7.6 跳过、简版与中断

- **点按跳过**：召唤到揭示之间任意点按 → 直接落「可选」终态（全部翻面、领位已抬），只响一声 `tap`。
- **同日简版**：同一天第二次起，发牌与揭示合并——三张直接正面落位（240ms）。
- **切后台 / 来电**：计时暂停；回来直接落「可选」终态，不重播。
- **杀进程**：手牌已入档；重启后 150ms 淡入恢复到「可选」，**不重洗**（§9.2）。

## 8 · 交互语法

### 8.1 手势表

| 手势 | 在哪 | 结果 | 永远不会 |
|---|---|---|---|
| 点侧牌 | 所有牌阵 | 送到领位（`rung` + 8ms 震） | 落定 |
| 左右滑 | 扇 / 台 / 轨 / 册 | 换领位；甩动超阈值翻一格；两端橡皮筋 | 落定 |
| 长按（≥350ms 且不动） | 牌的上半张（指纹区以外） | 审视；松手回位 | 落定 |
| 点领位 | B / C 级 | 落定 | — |
| 按住指纹区 | A / S 级领位 | 环满即落定；中途松手按退回时长回落 | — |
| 下拉领位 > 64px | 委托牌 | 降档（= 现有「换一个」） | — |
| 左右拖过 96px | 只限她的提议牌（§6.4） | 右 = 接受，左 = 不换 | — |
| 点出口铭牌 / 系统返回键 | 有出口的牌桌 | 收牌（= 等会儿 / 算了） | — |
| 点牌桌外空白 | 只限 B / C 级且允许不选的场景 | 收起 | 落定 |

「长按 = 审视」与「按住 = 落定」都是按着不放，所以**空间上分开**：指纹区只占领位下沿 52px，其余位置的长按一律是「看」。这和原型的做法一致——原型把指纹区从其他手势里显式排除了（`ui.js:17`，见 25 §1）。

### 8.2 落定的分量：代价越重，手势越重

| 级 | 代价 | 手势 | 满格 | 退回 |
|---|---|---|---|---|
| C | 无 / 可逆 | 点 | — | — |
| B | 几乎无 | 点领位 | — | — |
| A | 消耗资源 | 按住指纹区 | 0.5s（用道具 / 买东西） | 0.35s |
| A | 当日不可逆 | 按住指纹区 | 0.9s（接单，沿用 `HoldButton` 900 / 350 / 8 步） | 0.35s |
| 失败档 | 认输 / 接补救 | 按住 | 1.2s（认输，沿用现值）/ 0.6s（接补救） | 0.30s |
| S | 改变主线 | 按住指纹区 | 0.9s | 0.35s |
| S 负向 | 销毁存档 | 按住 | 2.0s（沿用现值） | 1.0s |

### 8.3 防误触六条

1. **侧牌永不落定**——全部牌阵统一，没有例外。
2. 揭示完成前整桌断命中，只留「点按跳过」层。
3. 落定瞬间锁桌：一下 = 一声 + 一震（`_locked` 语义）。
4. 收起 / 隐藏的牌桌一律 `IgnorePointer`——本仓库真踩过「一颗看不见的按钮替派单板的指纹挨点」（23 §3.4）。
5. 指纹区与审视区空间分离（§8.1）。
6. 手指位移 > 8px 即判为滑动，不再触发点按。

### 8.4 对 23 号 §12.5 分歧的建议裁决

23 号落地后留了一个分歧：物件台「点侧卡 = 送位并直接用掉」，铭牌轨「点侧牌 = 只送位」。按 §8.3 第 1 条，**建议统一成两步**：侧牌只送位，道具改为「领位按住 0.5s 使用」。

代价：`item_drawer_test.dart`「有货的照常」那条冻结断言要从「tap 侧卡 → 回调」改成「tap 侧卡 → 按住领位 → 回调」（23 号估过约 10 行）。动冻结测试需要你授权——列为 §19 的 D6。

## 10 · 逐场景设计卡

> 每张卡回答同样几件事：现在什么样 → 改成什么样 → 怎么落定 → 选完去哪 → 她怎么演 → 边界。

### 10.1 ★ 委托三选一（A · 机制 M1 + M2）

- **现在**：她指派一块玻璃单 → 指纹 0.9s 接；板下「换一个 / 等会儿」；换单券无入口。
- **改成**：她发三张，**位置即身份**——左「补短」（专治你最弱的那一维）· 中「贴主线」（离主线最近）· 右「随缘」（池里随一张）。身份写进角标：`QUEST · 补短 · 力`。
- **默认领位**：中位「贴主线」——系统的倾向**摆在明面上**，不是暗中推送。
- **落定**：领位指纹区按住 0.9s（与现在接单同一个手势、同一份手感）。
- **四个把手**：下拉某张 = 降档；「换单券 ×N」= 三张同档重发；「等会儿」= 收牌回袖（手牌持久）；右下暗牌「随你」= 她挑。
- **余波**：选中的压指纹印飞向执行台；没选的翻回牌背收进她袖中——之后在聊天里说「换一张」，她就从袖中这两张里换（docs/18 §2.2：「候选中未被选中的单子不丢弃，小祥手里可见」——这句设计终于有了画面）。
- **主线环**：不进三选一。主线日只发一张**锁定单牌**（对阵）：角标 `MAIN · 第 n 环`，印位旁一把小锁；下拉无效，她：「主线不换。」
- **她**：领位在最难那张停留 >1.5s →「……你认真的？」；落定最难 → mood `proud`；落定最易 → `smug`；选「随你」→ `pleased` + act `nod`。台词见 §11.4。
- **边界**：候选只有 2 张 → 二选一（仍是一大一小，不对称）；只有 1 张 → 退回单牌；前 10 单 → 不开三选一；正在执行中 → 不发牌（唯一执行中，CTA 显示「执行中」）。
- **依赖**：三张一摊，内容池的重复感会**提前三倍暴露**（docs/19 A5：可见池约 18 条）——建议与 docs/19 P0-5「日常内容扩充」同批或在它之后。

### 10.2 立命：选目标（S · 表现 + 小逻辑）

- **现在**：输入框 + 6 个预设 chip（三个月跑完半马 / 一个月早睡早起 / 考研上岸 / 半年减重 10 斤 / 学会画画 / 变优秀），类别靠关键词猜。
- **改成**：册阵——10 张「命题牌」= `goal_gen.dart` 的十类：**奔跑 · 轻盈 · 力量 · 开口 · 上岸 · 早起 · 作品 · 上线 · 自信 · 变强**，末尾一张「空白牌」。每张：类别名、主维度单字印、一句示例目标、她的批注。
- **选中**：命题牌翻面变成输入面，示例目标已填好、可改——**类别由你直选**，关键词识别退为兜底（顺带减少「梦话」误判）。空白牌 = 现在的纯自由输入。
- **被驳回**（`vague`）：牌面 glitch 两帧、裂开一道缝、弹回牌册；她 mood `annoyed` + act `poke`（原型 `flows.js:129` 同款），台词沿用 `vague`。
- **落定**：S 级，按住指纹区 0.9s——这是整个绑定仪式最重的一下。

### 10.3 访谈（整段 A，单答 B · 表现）

- **现在**：问题 + 3 个 chip + 自由输入 + 进度轨（`interview_deck.dart`）。
- **改成**：「事件牌 + 答案轨」——上方一张事件牌（问题 = 牌名，角标 `Q 2 / 3`），下方竖排轨阵：3 个答案 + 1 张空白「自己写」。
- **进度实体化**：右上角一叠牌，还剩几题就有几层厚；每答一题，顶上那张飞走。
- **影响预告**：会改变结果的答案（如「天天熬夜」会把第 1 环换轻档，`goal_gen.dart` `interviewIndicatesHeavyBurden`），牌面角标写「影响：首环档位」——信息透明原则。
- **余波**：答完一题，事件牌连同答案压成一张「档案卡」，飞进她胸口——访谈即第一批记忆（`memory.dart`），这次是看得见的。

### 10.4 开牌：首目标三环揭晓（S · 表现）

- **现在**：烟花 + 拆环。
- **改成**：暗阵，三张命途牌背扣着发出，按 **E → D → C** 依次自动翻开（间隔 280ms），翻完三张一起升起，化成她头顶的三个环（接 24 号 S04「环从脚下挂到头顶」）。只开牌、不选牌。
- 翻完可接原型那句没移植的对白「够得着。/ ……试试吧。」（轨阵，零新增设计）。

### 10.5 见面礼三选一（S · 机制 M3）

- **现在**：绑定完成固定发双倍卡 ×1。
- **改成**：「新手三选一」——**双倍卡 / 暴击芯片 / 免死金牌**，扇阵，物件牌放大到 L 档。这是宿主的第一个真选择，像宝可梦选御三家：它奠定「你的选择会被记住」。
- **她的批注**：双倍卡「贪的选这个。」/ 暴击芯片「赌的选这个。」/ 免死金牌「怂的选这个。」
- **落定**：按住 0.9s；没选的两张熄灭，**以后不会再以见面礼出现**——不可得，才有分量。

### 10.6 使用道具（A · 表现）

- **现在**：物件台（23 甲）；点侧卡 = 送位并直接用掉。
- **改成**：物件台不动；侧牌只送位；领位按住 0.5s 使用；领位下方一行说明（`Item.desc` 原文，如「本单经验翻倍。和暴击叠，就是四倍。」）。
- **余波**：领位卡化成光粒钻进当前委托，执行面板上的委托牌角多一枚 `×2` / `✦` / `◆` 印。
- **边界**：已生效 → 状态线实心 + 角标「已生效」，再按她说「已经挂上了。」；无货 → 灰 + `持有 ×0`，点了她说「没货。去补给。」（抽屉里的「去补给」键已按你的指定删除，入口回到底栏「补给」）。

### 10.7 证据来源（C · 表现）

- **现在**：Material `ListTile` 底部弹层——全 App 唯一的 Material 长相（25 §4.1-g）。
- **改成**：从证据槽位置弹出两张微牌：「◉ 拍照 · 现场拍一张」「▣ 从相册选 · 挑一张现成的」（字形与文案原样），点即走。这一处的价值主要是**消灭异类长相**，不是仪式。

### 10.8 认输书（失败档 · 表现）

- **现在**：按住 1.2s，屏幕随进度压暗（veil 最多 75%）。
- **改成**：按下「认输」时，执行面板上升起一张「认输书」（对阵单牌，残局牌种）：委托名 + 已用时 + 一句「认输不丢人。丢人的是不敢接。」（`content.dart:12` 原句）。按住期间，墨迹从指纹处晕开，veil 同步压暗（保留现有联动）；满格 → 牌面落一个灰印「认输」→ 进失败页。
- **不加任何新阻力**：时长仍是 1.2s，只是把「按住」放到了一张牌上。

### 10.9 回应（B · 表现）

- **现在**：铭牌轨（23 乙）。
- **补两件**：① 结算页的「找小祥说说 / 保存战报」做成轨尾两枚**次级小牌**（同族、更薄、不参与领位）——长相统一；② §4.2 注里那 6 处原型对白，补回时一律走这条轨。

### 10.10 升级 · 权限提升（S · 机制 M4）

两个方案，**建议先乙后甲**（乙只是多一个奖励来源；甲是一整个新系统）：

- **乙 · 加点**：每次升级给 2 点自由属性点；六边阵围着雷达，选一维 → 雷达画出虚线预览 → 按住 0.9s 落定，雷达实线弹簧长过去。正好对上系统流的老母题：「叮！属性点 +2，请宿主分配。」
- **甲 · 天赋三选一**：三张天赋牌从经验条顶端掉落（§7.3），选一张**永久生效**，嵌进档案页天赋槽。天赋只做加成、不做惩罚：

| 天赋 | 效果 |
|---|---|
| 早起鸟 | 9:00 前提交的委托 EXP +1 |

| 重抽手 | 每日免费重抽 1 次 |
| 铁胃 | 补救单时限 +12h |
| 嘴下留情 | 她的毒舌档位上限 −1（12 号三档） |
| 专精 · X | X 类委托金币 +2 |
| 暴击体质 | 基础暴击率 +3% |

出口：「都不要」→ 折现 20 金币（杀戮尖塔歌唱碗）。注意前四条天赋**改的是抉择协议本身**——roguelike 最好玩的就是这种「规则在变」的元成长。

### 10.11 补救（失败档 · 表现；三选一 = M5）

- **现在**：失败页【……接。/ 今天算了。】
- **表现层**：残局牌（对阵）——黯场里只亮一张补救卡：角标 `RESCUE` + 任务名 + 半量时长 + 截止时间；**中性青、禁暖色**（24 号 S14：「希望是靠机制给的，不是靠打光给的」）。按住 0.6s =「……接。」；牌下一枚铭牌「今天算了。」

### 10.12 换目标 / 新章（S · 表现；候选来源 = M6）

- **现在**：主线页「换目标」→ 输入框 + 5 个预设（含「先问小祥」）+「算了，不换」；收官时自动钉好下一条，没有选择。
- **改成**：「新章三选一」——她发三张命途牌：**进阶**（同类更难更长，5~8 环）· **旁支**（相邻类别）· **补短**（最弱维对应的类别）；外加一张空白牌「自己写」和一张她的牌「先问小祥」（翻开即进对话）。

## 11 · 她的戏份

### 11.1 六拍对位表

只用现有的 12 种 mood 与 19 个 act（`stage/stage_port.dart`），不新增表情资源：

| 拍 | mood | act | 台词语气 |
|---|---|---|---|
| 召唤 | `focus` | S 级加 `present` | 发布 |
| 发牌 / 揭示 | `focus`；见 ≥A 时一瞬 `surprised` | ≥A：`surprise` | — |
| 端详 | 跟着领位走：最难 → `smug`；最易 → `cold` | — | 追问（闲置 8s，只说一次） |
| 待发（按住中） | `focus` | — | 沿用 `waver`：「……犹豫了？」「手抖什么。」「按住。别松。」（`content.dart:72`） |
| 落定 | 难 → `proud`；易 → `smug`；随你 → `pleased` | `nod` | 结算 |
| 收牌（等会儿 / 算了） | `cold` | `lookAway` | 毒舌 |
| 失败档 | `sad` → `neutral` | `down` | 平 |

### 11.2 视线跟着领位

原型有 `Stage.look({x, y})`（`flows.js:106`）；Flutter 的 `StagePort` 只有 `mood / act / idleMood` 三个口子。要让她的眼睛跟着领位走，得给端口补一个 `look(point)`——列为依赖。补不上时降级为只换 mood，不影响任何功能。

### 11.3 台词节流

- 每 2.5s 最多一句；
- 换领位时**默认不说话**，只有两种例外：领位第一次落到最稀有的那张，或落到「随你」暗牌；
- 端详闲置 8s 说一句追问，之后不再催——不做「催促循环」。

### 11.4 台词样本（四种语气 · 宿主可改）

| 时机 | 语气 | 台词 |
|---|---|---|
| 召唤 | 发布 | 叮。请宿主三选一。 |
| 领位停在最难那张 | 追问 | ……你认真的？ |
| 闲置 8 秒 | 追问 | 还在挑？挑的这几秒，够你先开个头了。 |
| 落定最难 | 结算 | 行。我记下了。做不到别哭。 |
| 落定最易 | 毒舌 | 保守。也行，先活下来。 |
| 选「随你」 | 结算 | 交给我？……眼光不错。 |
| 重抽 | 毒舌 | 挑三拣四。券我收了。 |
| 降档 | 毒舌 | 降。口头巨人进度 2/3。 |
| 收牌 | 毒舌 | 行。牌我先收着，跑不了。 |
| 补救 | 平 | 做一半，这笔就划掉。 |
| 买最贵的 | 毒舌 | ……今天这么阔？ |

文案守 07 号：毒舌但靠谱、四种固定语气、不说「加油」、「！」只在「叮！」里出现；涉及数字时引用真实数据（12 号），如审视背面「这类单你认输过 2 次。」

### 11.5 牌面批注怎么来

- 本地模板为真源：按「牌种 × 身份 × 稀有度」组合，每格 2~3 句，≤16 字；
- LLM（`SystemCopyProvider`）可以改写，但**绝不阻塞发牌**：揭示时先显示模板句；LLM 在 1.2s 内回来就用打字机（34ms / 字）把新句子覆盖上去，超时就保持模板——对齐 docs/18 总原则「LLM 一切调用必须可兜底」。

## 13 · 视觉规范

### 13.1 真源口径

- **数值**以 `app/lib/design/tokens.dart` 为准（B 系）：底色 `C.voidBg #03060E` / `C.abyss` / `C.navy`，主色 `C.blue #38E1FF`，文字 `C.ice` / `C.mist` / `C.dim`，描边 `C.line`（.26）/ `C.line2`（.12），稀有度 `C.rF ~ C.rS`；字体 **ShuHei**（标题）/ **FangYuan**（正文与她的话）/ **Tektur**（数字）/ **KodeMono**（系统读数）；缓动 `kOut = Cubic(.16, 1, .3, 1)`。
- **原则**借 DESIGN.md：玻璃 + 辉光 + 斜切角、稀有度色只给稀有度、禁 emoji、禁三等分卡列、禁居中英雄布局。
- 注意：AGENTS.md 里写的 Rajdhani / Noto Sans SC / JetBrains Mono 与 `#0A0E1A` 是 A 系（Stitch）口径，App 实际用的是上面这套（25 §1 已指出两套口径并存）。

### 13.2 牌框

- 底：`C.navy` α.86 + 背景模糊 12（「全息描边」关时改 α.94 纯色）；
- 描边：1px `C.line`；领位升到 `C.blue` α.6 + 外辉 blur 22；
- 圆角 12；斜切 12px 在右上（所有牌种统一；残局牌改在左下）；
- 扫描线只出现在牌背与 S 级牌面。

### 13.3 稀有度只给稀有度

只有委托牌（以及将来带稀有度的掉落）用稀有度色：左侧 3px 条 + 同色柔光（rarity α.25，blur 16）+ 印位大字母。其余一律青色。**天赋不分稀有度**——要分档就用 1~3 道青色内框（Ⅰ / Ⅱ / Ⅲ），不把稀有度色挪作他用。

### 13.4 S 级全息箔

揭示时一道斜向流光扫过一次（1.6s），之后每 6s 闲置扫一次：青 → `C.rS` → 青，α.18。减弱动态或「全息描边」关时取消。

### 13.5 辉光预算

**同一时刻只有一张牌在发光——领位。** 侧牌没有外辉；S 级全息箔算作辉光，S 级领位因此不再额外叠外辉。光是语言，不是装饰。

### 13.6 与「禁三等分卡列」的兼容

DESIGN.md 明确禁止三张等宽卡排成一行——而 roguelike 三选一最常见的画法恰恰就是这个。本体系七种牌阵**静止时没有一种是三张等大平排**：扇阵领位 1.0 抬起、侧位 .82 下沉外倾；册阵逐级缩小；台阵领位放大；轨阵阶梯错位。层级本身就是答案。

## 14 · 可读性与无障碍

- **减弱动态**：无飞行、翻面、旋转、扫描线、全息箔；领位靠描边 + 辉光 + 状态线表达；切换 120ms 淡入淡出；落定只换状态。**前置条件**：25 号 G1——全局 reduced-motion 至今没接线（`fx_layer` 参数恒为 false），本体系读的是同一个开关（`rail_base.dart` 的 `railReduceMotion`），G1 不修，这一条只在牌桌内生效。
- **字号**：所有必要信息缩放后 ≥13px（23 号已用测试钉住 `kItemNameSize * kItemSideScale >= 13`，新牌阵照此各钉一条）；系统字号 ≥1.3 自动切竖排轨阵。
- **色觉**：稀有度永远「字母 + 颜色」；代价永远「图标 + 文字」；状态线配角标文字。
- **读屏（TalkBack）**：每张牌一个语义标签，如「第 2 张，共 3 张，领位，B 级，早起 20 分钟，经验 6，金币 7」；按住类落定在读屏模式下改为「双击确认」。
- **单手**：指纹区在屏幕下 40%；出口铭牌在拇指区；只用左右滑，不用上滑（避开系统手势条）。
- **震动可关**（设置里已有）。

## 15 · 边界与异常

| 情况 | 处理 |
|---|---|
| 只有 1 个选项 | 不摆扇；对阵单牌，领位即唯一（如「收工。」） |
| 0 个选项 | 空态牌背 + 倒计时（10.18） |
| 只有 2 个 | 二选一：一大一小，仍不对称 |
| LLM 超时 / 无 Key | 牌面全部来自本地模板；批注保持模板句 |
| 发牌中来电 / 切后台 | 暂停，回来落「可选」终态 |
| 杀进程 | 手牌已入档，150ms 淡入恢复，不重洗 |
| 连点 / 多指 | 落定锁桌；第二根手指无效 |
| 按住中被打断（拉下通知栏） | 视为松手，按退回时长回落 |
| 手牌是昨天的 | `rollDay` 作废，与隔夜日常同口径 |
| 正在执行中又点委托 | 不发牌（唯一执行中） |
| 金币不足 | 货架牌灰锁；按住无效，她说一句 |
| 口头巨人生效中 | 称号册封印 |
| 前 10 单 | 不开委托三选一 |

## 20 · 怎么算「做成了」

### 20.1 截屏判据（沿用 25 号）

每个 S / A 级场景逐张给你过目，你说「我愿意截屏给别人看」才冻结。

### 20.2 时间预算

| 级 | 叮 → 可选 | 落定 → 退场 | 同日重复 |
|---|---|---|---|
| S | ≤ 2.0s | ≤ 1.0s | 简版 ≤ 1.0s |
| A | ≤ 0.8s | ≤ 0.7s | ≤ 0.4s |
| B | ≤ 0.35s | ≤ 0.3s | — |
| C | 即时 | 即时 | — |
| 失败档 | ≤ 0.3s | ≤ 0.3s | — |

### 20.3 手感清单（只能真人验）

1. 领位抬起像是被手指托起来的，不是「变大了」；
2. 侧牌让位是双向的：领位往前抢，邻位往后缩；
3. 指纹按满那一下，想截屏；
4. 翻牌顺序让最稀有的那张最后出来；
5. 没选的牌有明确的去处，不是凭空消失；
6. 她的视线跟着领位（若 §11.2 已补）；
7. 打开「减弱动态效果」后一点都不晃；
8. 一周用下来，侧牌**从没**被误落定过；
9. 委托三选一 10 秒内能选完，不卡壳；
10. 七种牌阵放在一起，一眼能分出是同一家族、又各不相同。

### 20.4 本地记账（只写进 history，不上报）

| 指标 | 健康区间 | 越界说明什么 |
|---|---|---|
| 委托三选一决策时长中位数 | 3~10s | <1.5s：三张没区别；>20s：选择困难 |
| 三个位次的选取占比 | 每位 20%~50% | 某位连续两周 >60%：身份失衡，调池子 |
| 重抽率 / 降档率 / 随你率 | 观察 | 随你率很高 = 宿主其实想要「被指派」 |
| **自选单完成率 vs 指派时代基线** | 自选 ≥ 指派 | **这是整套设计的核心假设**：自己选的，更愿意做完 |
