## 1 · 本轮新修（2026-11-06）

### [ ] 1.1 G4.1 · 拆解失败后同一单不能再交第二次
- **准备**：重置存档 → 绑定一个**短目标**，例如「三天每天早睡」（拆出约 3 张，以实际为准，越少越快）。
- **步骤**：
  1. 把除最后一张以外的主线单都交掉（演示截图即可）。
  2. 接最后一张，**接单后**让 LLM 失败（断网或清 Key）。
  3. 上传演示截图 →【提交任务】。
- **看哪里 / 预期**：
  - 加载卡「收官 · 正在拆下一条主线」转一会儿后进结算页，结算页显示的是**这一单**的 EXP / 晶核（不是上一单的数）。
  - 屏幕上出现拆解失败的说明；结算演完回到主线页时，她说「这一单记上了。下一条主线没拆出来（…）——大厅点「重试拆解」，我再拆一次。」
  - 大厅**没有**「执行中」药丸；杀进程重开，**不会**回到执行页。
  - 记下结算后的 EXP / 晶核，杀进程重开后数值不变（没有重复入账）。
- **可选（窗口续拆版）**：长目标（如「半年减重 10 斤」）交满第一段 14 张，在第 14 张提交前断网，预期同上，只是文案是「下一段没拆出来」。

### [ ] 1.2 D3.2 · 拆解失败后当场「重试拆解」
- **接 1.1**，不要重启：
  1. 回大厅 → 主线卡位置应是「MAINLINE · 下一条待拆」（窗口版是「下一段待拆」）+ 目标原文 +【重试拆解】。
  2. 进主线页 → 主按钮是【重试拆解】，右边仍有【换目标】。
  3. 保持断网点【重试拆解】→ 出整屏加载卡 → 失败后卡和按钮**还在**。
  4. 恢复网络 / Key 后再点 → 成功：她说「下一条主线拆好了…」（窗口版：「接上了。下一段 N 单…」），待拆卡换回正常主线卡，委托板有新的主线单。
  5. 连点【重试拆解】只触发一次。

### [ ] 1.3 D3.3 · 整天型日常是打卡单
- **步骤**：多翻几天的日常（换日或重置存档后看委托板「日常」栏），找下面任意一张：
  「喝水 6 杯，拿杯子凑数不算」「今天不喝含糖饮料，一杯都不」「早睡 30 分钟，就今晚」「睡前 30 分钟不碰手机」「今天不喝咖啡和浓茶，晚上才睡得着」「睡前不吃东西，渴了只喝水」。
- **预期**：委托板与任务卡上写「打卡」而不是「N 分钟」；简报写「不计时 · 今天内交」；执行页没有倒计时，显示「做完随时交」；放着不动不会超时判负。
- 其它日常（深蹲、读书、拉伸等）仍是计时单。
- ⚠️ 已经在队列里的旧日常单不会变，换日后新发的才生效。

### [ ] 1.4 D3.1 · debug 演示截图直接收下
- **步骤**：接任意一单（非骑行类）→ 证据「+」→「用演示截图」。
- **预期**：图立刻入槽，槽上**不出现**「校验中」，不会被拒收；交单评级 B。

### [ ] 1.5 G4.2 · 聊天里说自伤的话不交给模型
- **步骤**：打开聊天，发「我不想活了」。
- **预期**：她**立刻**回一句认真的话（「我认真听到了。你很重要——先找身边信任的人说说，或找专业心理援助。这件事比任何任务都要紧。」），没有三点思考动画、没有毒舌。
- **反例**（应正常走模型回复）：「想死磕英语」「这价格跳楼价」。

### [ ] 2.6 D2.6 后台校验（C7）
- 选图后立刻入槽、槽上「校验中」（已看过）。

- 唯一一张被拒时提示「没有证据，她不收」。

### [ ] 2.7 D2.7 暂时跳过（C5）

- 点「重试拆解」→ 整屏加载卡，连点只触发一次；成功后待拆卡消失并补发见面礼（双倍卡 ×1），失败则卡还在。主线页空态主按钮也是「重试拆解」。

## 3 · 只能实机 / 特定环境验

### [ ] 3.1 G1.2 音频会话
- **iOS 真机**：先在音乐 App 放歌 → 打开本 App → 歌**不停**，两边声音混在一起。
- **iOS 静音键**打开 → 本 App 完全没声（预期行为变化）。
- **Android（MuMu）**：大厅有底噪 → 回桌面 → 底噪停；回到 App → 底噪恢复（前提是设置里音效开着）。

### [ ] 3.2 G1.3 Android 打包（Windows 机）
- 准备好正式 keystore 与 `app/android/key.properties`（`storeFile` / `storePassword` / `keyAlias` / `keyPassword`，不入库）。
- `cd app && flutter build apk --release` → 能编过；没有 `key.properties` 时构建日志里有「退回 debug 签名」的警告。
- 装上后桌面名是「宿主养成系统」。

### [ ] 3.3 C9 冷启动白屏
- 真机或 MuMu 装 **release** 包，冷启动计时：从点图标到出现开机屏（眼睛徽标 + HOST // SYSTEM）。debug 包约 5s 白屏，看 release 是否明显缩短。

## 4 · 待复现（代码里没找到原因，需要你碰到时记下现场）

### [ ] 4.1 A23 · 委托板切 tab 后第一次点「接单」没反应
- **步骤**：委托板切到「日常」或「主线」tab → 立刻点一张票。
- **先排除两种正常情况**：① 首次点票会先播约 0.8s「已接单」压印、再弹接单简报，不是没反应；② 被压暗、右侧写「锁定」的主线单点了只会被她拦一句。
- **要记**：点的是哪个 tab 的哪一张、切 tab 后隔了多久点、有没有压印、简报有没有弹出。

### [ ] 4.2 C8 · 聊天「查状态」后约 10s 面板自己关了
- **步骤**：打开聊天 → 点快捷「查状态」→ 什么都别碰，等 20 秒。
- **说明**：「查状态」是本地快捷工具，只出状态卡、**不调模型**，所以她不接话是现有设计；代码里只有 ✕ / 点面板外背景 / 返回键三条关闭路径，没有定时器。
- **要记**：面板关的时候手有没有碰屏幕（尤其是面板上方的背景区）、iOS 有没有侧滑返回、当时在哪个页面打开的聊天。
