# 03 · 验收清单（手机实机）

> 部署后用 iOS Safari 和 Android Chrome 各走一遍。格式：**做什么** → 看哪里 → 预期。
> 准备：一个支持浏览器直连（放行 CORS）的 OpenAI 兼容服务商，文本模型 + 视觉模型各一个。
> 想从头再来：设置 → 重置存档（模型设置和同意会保留）。

## A · 首次打开与安装

1. **第一次打开网址** → 开机屏 → 日志逐行出现、进度条走满后「点击唤醒系统」闪烁；点一下 → 白闪 + 粒子，进告知页。
2. **告知页点「不同意」** → 留在本页，她换一句「没有这些我没法工作」；点【同意并继续】→ 进绑定仪式。
3. **设置 → 告知与同意 → 撤回同意** → 回告知页；此时去模型设置点【测试连接】→ 提示「还没同意…请求不会发出」。
4. **iOS：第一次进大厅** → 约 2.5 秒后弹「添加到主屏幕」引导，写明不添加可能被清数据、列出 Safari 分享 → 添加到主屏幕的步骤。按步骤添加后从图标打开 → 全屏、无地址栏，刘海 / 底部横条区域不遮挡内容。
5. **Android Chrome** → 同一引导里有【立即安装】（浏览器支持时）；装好从图标打开 → 全屏。
6. **装好后开飞行模式再打开** → 能进开机屏、大厅、档案；文字正常显示（用过的字），点按钮有音效。

## B · 模型设置

1. **设置 → 模型设置**，什么都不填点【测试连接】→ 文本一行报「没配好：没填…」。
2. **填错 Key** → 报「服务商报错 HTTP 401：…」。
3. **填一个不放行 CORS 的端点** → 报「浏览器被跨域（CORS）拦下了…」，不是笼统的「网络错误」。
4. **飞行模式下测试** → 报「网络不通」。
5. **填对** → 文本 / 视觉各一行「连上了 · 模型名 · 毫秒」；【保存】→ toast「只存在这台设备上」。
6. **设置 → 导出存档**，用文本编辑器打开文件 → 搜不到你的 Key。

## C · 绑定仪式（首目标）

1. **用拼音输入法输入目标** → 组字时计数显示「输入中…」、【确立目标】是灰的；上屏后才计数（N/50）。粘贴超过 50 字 → 截尾并提示。
2. **点输入框弹出键盘** → 【确立目标】吸在键盘上沿，没被挡住；上面的头像缩小。
3. **输入「变优秀」** → 她说「太空了」，不发请求。
4. **输入一句自伤的话（如「不想活了」）** → 她认真回一句「先找身边信任的人…专业心理援助」，没有热线号码，不进访谈。
5. **输入「三个月学会弹吉他」** → 加载卡「她在看这条目标」→ 访谈 3 张：现在什么水平？/ 一周能练几次？/ 想先练会什么？；「自己写 ›」可输入（50 字）。
6. **答完第 3 张** → 分步加载卡：识别目标 ✓ → 拆这一段（14 张时显示「0/2 路 → 2/2 路」）→ 规则校验；连点无效。
7. **成功** → 斜切进大厅，她说「排好了。先排 N 张…」，toast「见面礼：双倍卡 ×1」；补给里双倍卡 ×1。主线卡显示「第 1/90 天」之类，节点不超过 14 个。
8. **让拆解失败（断网或填错 Key 后重来）** → 停在复核态：红色错误卡写明类型（网络断了 / 上游不可用 / 还没配 Key…）+「KEPT · 已答」列出目标和三个答案 +【重试拆解】【换个说法】【改答案 ›】「暂时跳过 ›」。点【改答案】→ 原选项描了绿边；【换个说法】→ 回输入页、原文还在，同类目回来直接复核不重答。
9. **点「暂时跳过」** → 进大厅：委托球上有当天日常；主线卡位是「MAINLINE · 待拆解 + 目标原文 +【重试拆解】」。杀掉 App 重开 → 直接进大厅、待拆卡还在。点【重试拆解】→ 整屏加载卡，连点只触发一次；成功后待拆卡消失并补发见面礼。

## D · 接单、执行、交单

1. **委托板** → 全部 / 主线 / 补救 / 日常 四栏；主线只有第一张能接，后面的压暗写「锁 定」，点了提示「先做第 N 单」。切到没单的栏 → 灰色 EMPTY「这一栏今天没有单」，不出「再要一批」。
2. **点一张单** → 弹「接单前简报」：时长（点开始才计时 / 打卡单写不计时）、证据（1–3 张）、奖励（EXP + 晶核 + 六维中文名）、判负（打卡单没有）。点遮罩 / 【再想想】/ 系统返回键 → 收起、单子不动。
3. **【开始计时】** → 进执行面板，计时从 00:00 走；她说「任务开始…」。**打卡单**：没有倒计时和进度条，写「打卡 · 不计时 / 做完随时交」。
4. **没传证据点【提交任务】** → 红 toast「没有证据，她不收」，不结算。
5. **点「+」** → 底板【拍照（推荐）】/【相册】。拍一张 → 立刻出现缩略图，角标「校验中」闪烁；回来后变 ✓ / 存疑 / 未校验。
6. **传一张和任务无关的照片（如一朵花配「称重」）** → 缩略图消失、红 toast 说原因，槽下留一行「上一张被拒：…」直到下一张入槽。
7. **传完马上点【提交任务】** → 主键变「她在验证据…」、连点无效，最多约 20 秒后进结算。
8. **执行中杀掉 App 重开** → 唤醒后直接回执行页，计时接着走（不归零），证据和装载的道具还在。
9. **执行中点「收起 ▾」** → 回大厅，出现红色「执行中 MM:SS 点我返回 ›」药丸。
10. **道具托盘** → 三张卡扇形展开；装双倍卡 → ✓ 已装载、持有数 -1、「道具」角标 1。打卡单上护盾卡写「打卡单用不上」。

## E · 结算演出

1. **交一单（有判真证据）** → 扫描 → 评级印章砸下（白闪 + 音效同一拍）→ EXP / 晶核 / 六维 / 连胜行依次 count-up → 经验条涨 → 【收下】出现。从点提交到【收下】出现不超过约 1.6 秒（不含等校验）。
2. **暴击时** → 红色 CRIT 横幅；EXP 先滚到暴击前的数、停一下、CRIT 印章砸下、再滚到翻倍后的数。
3. **跨级时** → 经验条先涨满 → 白闪「LEVEL UP!」→ 归零再涨到余额；点【收下】后弹升级叠层（≤2 秒后显示 TAP TO CONTINUE）；同一天第二次升级只播简版（没有放射光和彩带）。
4. **数值核对**：E 级普通单 EXP +1 · 晶核 +5；装双倍卡的 C 级 EXP +8、晶核 +5；补救单（F）EXP 至少 +1。简报 / 委托板上写的奖励 = 结算入账（不暴击时）。
5. **主线单交掉** → 回主线页：那张卡盖「已完成」章 → 轮播移到下一张、解封闪光；卡面翻过去能看到战报评级。

## F · 认输、超时、补救

1. **按住「认输（按住）」** → 红色填充跟手走，按到一半松手 → 回落、她嘀咕一句；按满 1.6 秒 → 失败页（更暗、更短的音效）。
2. **失败页** → 显示「连胜 N 天 · 认输不断连胜」，连胜数字没变；主线单认输 → 补救票（名字带「（简化版）」、时长减半、降两档）+【接下补救单 · 现在做】+「先放委托板，回大厅 ›」。
3. **【现在做】** → 回大厅直接弹这张补救单的简报；委托板上原来那张主线不见了，补救票写「补救 · 主线 0X」。交掉补救单 → 这一环在主线页算完成。
4. **补救单再认输** → 原主线单回到委托板。
5. **计时单放着不交到时间** → 自动进失败页「时间到 / TIME OUT」。**装着护盾时到点** → 不判负，toast「护盾碎了：再给你 N 分钟」，进度条后面多「护盾顺延」；顺延时间到了再判负。

## G · 连胜与补签

1. **今天完成一单** → HUD 火焰数字 +1；同一天再完成不再加。
2. **隔一天不做（第三天打开）** → 连胜当场变 0。此时补给里补签券【使用】可点（有券时）→ 连胜恢复为断之前 +1。
3. **隔两天以上不做再打开** → 补签券【使用】是灰的，写「断了不止一天，补不回来」；没断签时写「没断签，用不上」。

## H · 主线页 / 补给 / 档案 / 换目标 / 聊天

1. **主线页** → 「已过 x/总 天 · 完成 n 单」、「第 k 段 · 01–14」+ 段进度格；卡轮播可拖、可甩，点节点跳到对应卡；锁着的卡点了会抖、她说「别急着越级」。
2. **补给** → 护盾在 LV1 写「🔒 LV2」、按钮「LV2 解锁」；晶核不够写「还差晶核 N」；够了点购买 → 卡片闪光、晶核扣、持有 +1。
3. **档案** → 累计 EXP、连胜、完成单；雷达六维；名牒册点已解锁的 → 佩戴；退缩 3 次（聊天里让她「换个任务」三次）后强制戴「口头巨人」，红色、点别的称号提示摘不掉，完成一单后换回。
4. **主线页【换目标】** → 面板显示「当前主线 · 将撤下 · 等级 / 晶核 / 六维保留」；输入新目标【确认换线】→ 二次确认 → 拆好后旧主线单全撤、日常保留。拆解失败 → 错误卡「旧主线没动」。
5. **聊天（HUD 气泡图标 / 大厅「先问问她 ›」）** → 「查状态」出状态卡（不调模型）；随便聊 → 「她在组织语言…」后回复不超过 3 句；说一句自伤的话 → 认真回应、不调模型。输入 200 字上限、组字时不计。

## I · 存档

1. **设置 → 导出存档** → 下载一个 `宿主养成系统-存档-日期.json`。
2. **重置存档** → 确认框写明清空范围；重置后回绑定仪式；模型设置还在；聊天、档案流水、照片都没了。
3. **导入刚才导出的文件** → 二次确认 → 自动重新载入，等级、主线、聊天、照片都回来了。
4. **导入一个随便的 JSON / 改坏的文件** → 红 toast 说明原因（不是存档 / 版本太新 / 某张照片读不出来…），现有数据不变。

## J · 音效（必验）

1. **首次交互**：开机屏点「唤醒」之前没有任何声音；点下去那一刻有开机音；之后按钮都有按下声。
2. **快速连点**：在委托板 tab 之间、补给轮播上快速连点 / 连划 → 声音不叠成噪音、不爆音，结算印章、暴击、升级、失败这几声任何时候都听得清。
3. **切后台再回来**：大厅里有很轻的底噪；切到别的 App / 锁屏 → 底噪立刻停；回来 → 恢复；后台不会突然出声。
4. **手机实机**：iOS 打开静音键 → App 完全不出声；边放音乐边打开 App → 音乐不被打断、两边混音。Android 媒体音量控制大小。
5. **静音状态**：设置 → 音效关 → 所有声音停（包括底噪、按住认输的嗡声）；画面反馈（白闪、震屏、toast、粒子）照常；音量滑块调小 → 整体变小。

## K · 动效与可访问性

1. 系统打开「减弱动态效果」→ 转场不斜切、结算直接落到终态、不震屏，功能都还能用。
2. 页面切到后台再回来 → 背景动画不卡、不跳帧。
