# 03 · 验收清单（服务端版，手机实机）

> 部署后用 iOS Safari 和 Android Chrome 各走一遍。格式：**做什么** → 看哪里 → 预期。
> 准备：按 docs/02 部署好；用命令行建好管理员，再生成 2 个邀请码（给「A 号」「B 号」两个测试账号）；
> 一个 OpenAI 兼容服务商（文本模型 + 视觉模型），配在服务器 `.env` 的 `LLM_*` 里；另准备一把自己的 Key 用来测「用我自己的」。
> 想从头再来：设置 → 重置存档（账号、模型设置、同意都会保留）。
> 第 A~K 节是旧版清单按「数据在服务器上」调整后的版本；L~R 是服务端版新增。

## A · 首次打开、登录与安装

1. **第一次打开网址** → 开机屏 → 日志逐行出现、进度条走满后「点击唤醒系统」闪烁；点一下 → 白闪 + 粒子，进**登录页**（SIGN IN · 登录）。
2. **登录页点「有邀请码？注册一个」**，填用户名、密码（少于 8 位 → 她说「密码至少 8 位」）、邀请码（填错 → 「邀请码不对，或者已经用过了」）→ 填对 → 进告知页。
3. **告知页**列出五条：存档存在这台服务器上 / 目标和访谈经服务器发给模型服务商 / 聊天同上 / 照片存服务器并发给视觉模型、只有你能看 / 管理员技术上能接触数据。点「不同意」→ 留在本页，她换一句「没有这些我没法工作」；点【同意并继续】→ 进绑定仪式。
4. **设置 → 告知与同意 → 撤回同意** → 回告知页；此时去模型设置点【测试连接】→ 提示「还没同意首启告知页，请求不会发出」。重新同意后恢复。
5. **iOS：第一次进大厅** → 约 2.5 秒后弹「添加到主屏幕」引导（说明存档在服务器上、添加后全屏、断网也能看），列出 Safari 分享 → 添加到主屏幕的步骤。添加后从图标打开 → 全屏、无地址栏，刘海 / 底部横条区域不遮挡内容；**不需要重新登录**。
6. **Android Chrome** → 同一引导里有【立即安装】（浏览器支持时）；装好从图标打开 → 全屏。
7. **用同一个账号用错密码登录 6 次** → 第 6 次提示「登录太频繁了，N 秒后再试」；等一分钟恢复。

## B · 模型设置

1. **服务器没配 `LLM_*` 时**：设置 → 模型设置，「用服务器默认」下写「服务器还没配」；点【测试连接】→ 文本一行报「没配好：没填…」。
2. **服务器配好后**：「用服务器默认」写「文本 + 视觉已配」；【测试连接】→ 文本 / 视觉各一行「连上了 · 模型名 · 毫秒」；下面一行「今天已用：文本 n/150 次 · 验图 n/60 次」。
3. **切「用我自己的」**，填一个错的 Key → 【测试连接】→「服务商报错 HTTP 401：…」。填对 →【保存】→ toast「Key 加密存在服务器上，不会再回到浏览器」；再打开设置，Key 框是空的、占位写「已保存 …末4位（留空 = 不改）」；今日用量写「不限额」。
4. **断网时打开模型设置** → 提示需要联网（设置项不可改）。
5. **设置 → 导出存档**，用文本编辑器打开文件 → 搜不到你的 Key，也没有密码、同意记录。
6. **浏览器开发者工具 / 抓包** → 页面只请求自己的域名（`/api/...`），看不到模型服务商的域名和 Key。

## C · 绑定仪式（首目标）

1. **用拼音输入法输入目标** → 组字时计数显示「输入中…」、【确立目标】是灰的；上屏后才计数（N/50）。粘贴超过 50 字 → 截尾并提示。
2. **点输入框弹出键盘** → 【确立目标】吸在键盘上沿，没被挡住；上面的头像缩小。
3. **输入「变优秀」** → 她说「太空了」，不发请求。
4. **输入一句自伤的话（如「不想活了」）** → 她认真回一句「先找身边信任的人…专业心理援助」，没有热线号码，不进访谈；服务器今日用量不增加。
5. **输入「三个月学会弹吉他」** → 加载卡「她在看这条目标」→ 访谈 3 张：现在什么水平？/ 一周能练几次？/ 想先练会什么？；「自己写 ›」可输入（50 字）。
6. **答完第 3 张** → 分步加载卡：识别目标 ✓ → 拆这一段（14 张时显示「0/2 路 → 2/2 路」）→ 规则校验；连点无效。
7. **成功** → 斜切进大厅，她说「排好了。先排 N 张…」，toast「见面礼：双倍卡 ×1」；补给里双倍卡 ×1。主线卡显示「第 1/90 天」之类，节点不超过 14 个。
8. **让拆解失败（服务器没配模型、或用自己的错 Key）** → 停在复核态：红色错误卡写明类型（网络断了 / 上游不可用 / 还没配 Key / 今天额度用完了…）+「KEPT · 已答」列出目标和三个答案 +【重试拆解】【换个说法】【改答案 ›】「暂时跳过 ›」。点【改答案】→ 原选项描了绿边；【换个说法】→ 回输入页、原文还在，同类目回来直接复核不重答。
9. **点「暂时跳过」** → 进大厅：委托球上有当天日常；主线卡位是「MAINLINE · 待拆解 + 目标原文 +【重试拆解】」。杀掉 App 重开 → 直接进大厅、待拆卡还在。点【重试拆解】→ 整屏加载卡，连点只触发一次；成功后待拆卡消失并补发见面礼。
10. **拆第一段时（加载卡在转）杀掉 App 再打开** → 加载卡「她还在拆」接着走；拆完后进大厅（任务在服务器上跑完就落库）。

## D · 接单、执行、交单

1. **委托板** → 全部 / 主线 / 补救 / 日常 四栏；主线只有第一张能接，后面的压暗写「锁 定」，点了提示「先做第 N 单」。切到没单的栏 → 灰色 EMPTY「这一栏今天没有单」，不出「再要一批」。
2. **点一张单** → 弹「接单前简报」：时长（点开始才计时 / 打卡单写不计时）、证据（1–3 张）、奖励（EXP + 晶核 + 六维中文名）、判负（打卡单没有）。点遮罩 / 【再想想】/ 系统返回键 → 收起、单子不动。
3. **【开始计时】** → 进执行面板，计时从 00:00 走；她说「任务开始…」。**打卡单**：没有倒计时和进度条，写「打卡 · 不计时 / 做完随时交」。
4. **没传证据点【提交任务】** → 红 toast「没有证据，她不收」，不结算。
5. **点「+」** → 底板【拍照（推荐）】/【相册】。拍一张 → 立刻出现缩略图，角标「校验中」闪烁；回来后变 ✓ / 存疑 / 未校验。
6. **传一张和任务无关的照片（如一朵花配「称重」）** → 缩略图消失、红 toast 说原因，槽下留一行「上一张被拒：…」直到下一张入槽。
7. **传完马上点【提交任务】** → 主键变「她在验证据…」、连点无效，最多约 20 秒后进结算。
8. **执行中杀掉 App 重开** → 唤醒后直接回执行页，计时接着走（按服务器的接单时刻算，不归零），证据和装载的道具还在。**改手机系统时间**再看 → 计时不受影响（按服务器时间）。
9. **执行中点「收起 ▾」** → 回大厅，出现红色「执行中 MM:SS 点我返回 ›」药丸。
10. **道具托盘** → 三张卡扇形展开；装双倍卡 → ✓ 已装载、持有数 -1、「道具」角标 1。打卡单上护盾卡写「打卡单用不上」。

## E · 结算演出

1. **交一单（有判真证据）** → 扫描 → 评级印章砸下（白闪 + 音效同一拍）→ EXP / 晶核 / 六维 / 连胜行依次 count-up → 经验条涨 → 【收下】出现。从点提交到【收下】出现不超过约 1.6 秒（不含等校验和网络）。
2. **暴击时** → 红色 CRIT 横幅；EXP 先滚到暴击前的数、停一下、CRIT 印章砸下、再滚到翻倍后的数。
3. **跨级时** → 经验条先涨满 → 白闪「LEVEL UP!」→ 归零再涨到余额；点【收下】后弹升级叠层（≤2 秒后显示 TAP TO CONTINUE）；同一天第二次升级只播简版（没有放射光和彩带）。
4. **数值核对**：E 级普通单 EXP +1 · 晶核 +5；装双倍卡的 C 级 EXP +8、晶核 +5；补救单（F）EXP 至少 +1。简报 / 委托板上写的奖励 = 结算入账（不暴击时）。
5. **主线单交掉** → 回主线页：那张卡盖「已完成」章 → 轮播移到下一张、解封闪光；卡面翻过去能看到战报评级。
6. **交掉一段的最后一张** → 先出加载卡「这一段走完了」（服务器续拆）→ 再演结算；回主线页她说「下一段接上了」。

## F · 认输、超时、补救

1. **按住「认输（按住）」** → 红色填充跟手走，按到一半松手 → 回落、她嘀咕一句；按满 1.6 秒 → 失败页（更暗、更短的音效）。
2. **失败页** → 显示「连胜 N 天 · 认输不断连胜」，连胜数字没变；主线单认输 → 补救票（名字带「（简化版）」、时长减半、降两档）+【接下补救单 · 现在做】+「先放委托板，回大厅 ›」。
3. **【现在做】** → 回大厅直接弹这张补救单的简报；委托板上原来那张主线不见了，补救票写「补救 · 主线 0X」。交掉补救单 → 这一环在主线页算完成。
4. **补救单再认输** → 原主线单回到委托板。
5. **计时单放着不交到时间** → 自动进失败页「时间到 / TIME OUT」。**装着护盾时到点** → 不判负，toast「护盾碎了：再给你 N 分钟」，进度条后面多「护盾顺延」；顺延时间到了再判负。
6. **计时单接单后关掉 App，过了截止时间（装着护盾的话过了顺延时间）再打开** → 一进来就是失败页（服务器按服务器时间判）。

## G · 连胜与补签

1. **今天完成一单** → HUD 火焰数字 +1；同一天再完成不再加。
2. **隔一天不做（第三天打开）** → 连胜当场变 0。此时补给里补签券【使用】可点（有券时）→ 连胜恢复为断之前 +1。
3. **隔两天以上不做再打开** → 补签券【使用】是灰的，写「断了不止一天，补不回来」；没断签时写「没断签，用不上」。
4. **「一天」按账号时区算**：设置 → 账号里显示时区；手机改成别的时区不影响换日时刻。

## H · 主线页 / 补给 / 档案 / 换目标 / 聊天

1. **主线页** → 「已过 x/总 天 · 完成 n 单」、「第 k 段 · 01–14」+ 段进度格；卡轮播可拖、可甩，点节点跳到对应卡；锁着的卡点了会抖、她说「别急着越级」。
2. **补给** → 护盾在 LV1 写「🔒 LV2」、按钮「LV2 解锁」；晶核不够写「还差晶核 N」；够了点购买 → 卡片闪光、晶核扣、持有 +1。
3. **档案** → 累计 EXP、连胜、完成单；雷达六维；7 天战报；名牒册点已解锁的 → 佩戴；退缩 3 次（聊天里让她「换个任务」三次）后强制戴「口头巨人」，红色、点别的称号提示摘不掉，完成一单后换回。
4. **主线页【换目标】** → 面板显示「当前主线 · 将撤下 · 等级 / 晶核 / 六维保留」；输入新目标【确认换线】→ 二次确认 → 拆好后旧主线单全撤、日常保留。拆解失败 → 错误卡「旧主线没动」。
5. **聊天（HUD 气泡图标 / 大厅「先问问她 ›」）** → 「查状态」出状态卡（不调模型）；随便聊 → 「她在组织语言…」后回复不超过 3 句；说一句自伤的话 → 认真回应、不调模型。输入 200 字上限、组字时不计。**换台设备登录** → 聊天记录还在。

## I · 存档（导出 / 导入 / 重置）

1. **设置 → 导出存档** → 下载一个 `宿主养成系统-存档-日期.json`。
2. **重置存档** → 确认框写明清空范围（账号、模型设置、同意保留）；重置后回绑定仪式；模型设置还在；聊天、档案流水、照片都没了（打开旧照片的地址 → 404）。
3. **导入刚才导出的文件** → 二次确认 → 自动重新载入，等级、主线、聊天、照片都回来了。
4. **导入一个随便的 JSON / 改坏的文件 / 照片被改坏的文件** → 红 toast 说明原因（不是存档 / 版本太新 / 第 N 张照片读不出来…），现有数据不变。
5. **旧版（纯前端 PWA）导出的文件** → 能导入，进度回来（模型设置要在新版里重填）。

## J · 音效（必验）

1. **首次交互**：开机屏点「唤醒」之前没有任何声音；点下去那一刻有开机音；之后按钮都有按下声。
2. **快速连点**：在委托板 tab 之间、补给轮播上快速连点 / 连划 → 声音不叠成噪音、不爆音，结算印章、暴击、升级、失败这几声任何时候都听得清。
3. **切后台再回来**：大厅里有很轻的底噪；切到别的 App / 锁屏 → 底噪立刻停；回来 → 恢复；后台不会突然出声。
4. **手机实机**：iOS 打开静音键 → App 完全不出声；边放音乐边打开 App → 音乐不被打断、两边混音。Android 媒体音量控制大小。
5. **静音状态**：设置 → 音效关 → 所有声音停（包括底噪、按住认输的嗡声）；画面反馈（白闪、震屏、toast、粒子）照常；音量滑块调小 → 整体变小。音量设置留在这台设备上（换设备是各自的）。

## K · 动效与可访问性

1. 系统打开「减弱动态效果」→ 转场不斜切、结算直接落到终态、不震屏，功能都还能用。
2. 页面切到后台再回来 → 背景动画不卡、不跳帧。

## L · 多用户隔离与账号

1. **A 号、B 号各自注册、各自立目标** → 两边的等级、主线、委托板、聊天、档案互不相干。
2. **A 号交一单带照片**，记下缩略图地址（长按图片 → 拷贝图片地址，形如 `/api/evidence/xxx`）；**在 B 号登录的浏览器里打开这个地址** → 404，看不到图。
3. **没登录（无痕窗口）直接打开 `/api/state`、`/api/history`、上面那个图片地址** → 401。
4. **A 号在设置 → 账号里改密码** → 当前设备继续能用；A 号在另一台设备上的登录立刻失效（下一个操作回登录页，提示「登录过期了」）。
5. **管理员命令行 `disable B号`** → B 号所有设备下一个操作回登录页，且登录不进去；`enable` 后恢复。
6. **管理员命令行 `reset-password A号`** → A 号所有设备下线；新密码能登录。
7. **同一个邀请码给第二个人用** → 「邀请码不对，或者已经用过了」；7 天后的旧码 → 「邀请码过期了」。
8. **设置 → 退出登录** → 回登录页；断网后再打开 App → 不会显示刚才那个账号的缓存数据。

## M · 断网

1. **已登录状态下开飞行模式，杀掉 App 再打开** → 能进开机屏、大厅、档案、主线页，显示最近一次的状态；顶部有黄色「OFFLINE · 没联网，只能看，不能改」；文字正常显示（用过的字），点按钮有音效。
2. **断网时点接单 / 购买 / 交单 / 发聊天** → 提示「需要联网」，数据不变，联网后也不会自动补发。
3. **执行中断网** → 计时照常走秒；到点时不判负、不弹失败页，进度条下写「00:00 · 联网后结算」；**恢复联网** → 自动同步，服务器按服务器时间判（有护盾先碎盾，再超时才判负）。
4. **断网时打开设置** → 模型设置 / 导出 / 导入 / 重置 / 账号都提示「需要联网」；音效与音量照常能调。
5. **恢复联网** → 顶部提示消失，数据自动刷新到最新。

## N · 两台设备同时操作（同一账号，手机 + 电脑）

1. **手机上接一单** → 几秒内电脑上委托板少了这张、出现「执行中」药丸（不用刷新）。
2. **两台同时停在执行页，手机上交单** → 手机演结算；电脑上回到大厅，toast「另一台设备刚改过存档，已同步」，不演结算。
3. **两台同时对同一张单点【开始计时】** → 一台进执行页，另一台提示「你手上还有一单没交差」或「这张单已经不在她手里了」，不会出现两个执行中的单。
4. **两台同时点补给【购买】（各点一次）** → 晶核扣两次、持有 +2（两次都是真实购买）；网络抖动导致的同一次点击重发 → 只扣一次。
5. **电脑上打开聊天发一句** → 手机上打开聊天也能看到这一句和她的回复。
6. **手机在拆解（加载卡）时电脑上打开 App** → 电脑上也出加载卡，同一件任务的进度；拆完两边都同步到新主线。
7. **一台设备上重置存档，另一台还开着** → 另一台下一次同步回到空白档（绑定仪式）；之后它的写操作若基于旧状态 → 提示「另一台设备刚改过存档」并刷新。

## O · 服务器重启后数据还在

1. **`docker compose restart app`（或 `down` 再 `up -d`）** → App 下一次请求恢复正常；登录状态还在（不用重新登录）；等级、主线、聊天、流水、照片都在。
2. **重启时正好有一件拆解在跑** → 前端加载卡结束并报「网络断了」失败卡（答案还在），点【重试拆解】能重来。
3. **`docker compose up -d --build` 更新版本** → 数据都在；已打开的 App 回到大厅时自动切到新版本。

## P · 备份与恢复

1. **`docker compose exec app node apps/server/dist/cli.mjs backup`** → `backups/<时间戳>/` 下有 `app.db`、`uploads/`（有照片的话）。
2. **按 docs/02 第 4 节演练恢复**：停 app → 用备份替换 `data/` → 启动 → `users` 列出账号；登录后数据是备份那一刻的样子（之后的改动没有）。
3. **cron 每天备份** → 第二天 `backups/` 多一份、`backup.log` 有「备份完成」；超过 14 份时最旧的被删掉。
4. **备份目录里搜不到 `.env` 的内容**（`APP_ENCRYPTION_KEY` 单独保存）。

## Q · 额度与安全底线

1. **把 `LLM_DAILY_TEXT` 调成 3、重启**，用服务器默认 Key 的普通账号连续拆解 / 聊天 → 第 4 次起：拆解失败卡「今天额度用完了」（她说去设置里填自己的 Key，答案还在）；聊天回一句兜底台词并写明额度用完；设置里今日用量写满。管理员账号不受影响。
2. **把 `LLM_DAILY_VISION` 调成 1**，交两张照片 → 第二张按「未校验」收（评级最多 B），她说今天验图的额度用完了。
3. **同一个人 1 分钟内测试连接 11 次** → 第 11 次报「额度：太快了，N 秒后再试」。
4. **从别的网站（不同域名）伪造 POST 到 `/api/flow/buy`**（可用浏览器控制台在别的站点 `fetch` 试）→ 403「请求来源不对」。
5. **服务器日志（`docker compose logs app`）里搜** `sk-`、`Cookie`、密码、`data:image` → 都搜不到。
6. **上传一个改了扩展名的非图片 / 超过 2MB 的图** → 拒收并说明原因。
