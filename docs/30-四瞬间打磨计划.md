## 1 · 真源口径（一个必须先说清的事实）

仓库里存在**两套设计语言**，而 `AGENTS.md` 用 A 系的词描述了一套已被归档的设计：

| | **A 系 · 归档原型** `E:\repo\archive\app\index.html` | **B 系 · 中选原型** `prototype/opus-v2-dir/` |
|---|---|---|
| 任务对象 | 全息委托板 + **六空位** | **一块玻璃委托单** `#plate`（`ui.js:183-373`） |
| 发布 | **飞刀钉单**、红印「突」 | 单子砸落 + 稀有度**滚档** + **激光逐段刻字** |
| 接受 | **铆钉进度环** | **指纹 7 条同心弧**按住填充（`ui.js:169-181`） |
| 拒绝 | **横扫撕单** | 板下「换一个 / 等会儿」**按钮**（`flows.js:252-254`） |
| 详情 | 轻点 | 无（指纹区被 `ui.js:17` 显式排除） |
| 状态 | 2026-10-07 **已归档** | **仓库声明的真源**，Flutter 全程照它移植 |

**事实**：`opus-v2-dir` 全库 grep `飞刀 / 铆钉 / 红印 / 撕单 / 委托板` **零命中**；Flutter 侧 `app/lib/**/*.dart` 同样**零命中**。

**本轮口径**：**以 B 系（opus-v2-dir）为准**——App 就是照它做的，`tokens.dart:4` 与 `spring.dart` 的注释都指向它。
A 系那套更「战斗化」的语言（委托板 / 撕单 / 飞刀）作为**可选素材**，**不默认引入**（引入＝今日页/任务页返工，另立一轮）。

> ⚠️ 这一条要宿主点头。若宿主想要 A 系的战斗感，本文 §5 的批次一~四**依然成立**（都是补缺，不是重做），只是在此之上再加一轮「任务层换语言」。

## 7 · 未验 / 风险（诚实清单）

1. **原型真源未逐行核对**：Flutter 现状报告的「偏离」判定，部分依据源码注释里自述的原型行号；原型侧报告已给精确行号，两侧交叉一致，但**未做逐行 diff**。
2. **「铆钉」「飞刀」字面元素在两侧都不存在**——宿主口径里的这两个词，实际对应 B 系的「指纹七条弧」与「无」。
3. **瞬间 2 的「接受后盖章」**（原型 `.pl → scaleY(.012)` 260ms + 光痕 440ms + 爆散）在 Flutter 侧**未核**，可能在批次二里一起补。
4. **A 系语言是否引入未定**（§1）——不引入则今日页/任务页不动。
5. **`Live2DStage/Web` 是平台视图**，是否吞触摸未查（`main.dart:930-935` 注释称靠层序让位）。
6. **手感类改动不能靠测试验收**——测试只能钉住参数，钉不住「爽」。
