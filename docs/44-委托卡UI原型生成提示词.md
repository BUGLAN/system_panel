# 44 · 委托卡（CardSkin.duty）UI 原型 · 生成提示词

> 用途：给「宿主 SYSTEM」的**委托卡**出一张独立可预览的 UI 原型（不是页面、不是牌扇，只有卡本身）。
> 真源：`app/lib/widgets/card_skins.dart` 的 `_dutyFull`（M 档 148×240）+ `DutyFramePainter` / `DutyCrestPainter` / `DutyPipsPainter` / `DutyGroundPainter` / `DutySigilPainter` / `_statusLine` / `_seal` / `_specTable` / `_lootRow`。
> 原型只复刻**这一张卡**（含五态陈列），不包含 App 页面、底栏、角色、背景舞台。

---

## 一、给生成模型的提示词（整段复制）

```text
做一个单文件 HTML 原型，只画「宿主 SYSTEM」App 里的一张委托卡，M 档 148×240 逻辑像素，同时陈列五种状态：可接、执行中、已完成、待发布、已放弃。页面居中放 5 张卡（可横向排列、允许换行），深蓝虚空背景 #03060E，除了卡本身不要任何其他 UI。

卡是一份「系统铸的契据」：不是玻璃组件，是一块被铸造出来的硬牌。所有效果用纯 CSS/Canvas/SVG 画，不许用位图、不许用外部库、不许用 emoji，字体只用系统可用的中文黑体与等宽字体（可用 font-family: "ShuHei", "Noto Sans SC", sans-serif 这类回退链）。

【形状】圆角 6px + 左下角 45° 斜切 16px。卡必须完全不透明（背板 #050A14 打底），不许半透明、不许 backdrop-filter。

【六层卡边】沿同一条轮廓向内偏移，依次：
1. 外描边 1px：青色 #38E1FF，领位 α.40 / 侧位 α.18；待发布态走虚线（段 6 空 5）。
2. 暗边 1px，内缩 2px：纯黑 α.45。
3. 受光斜面：内缩 3.2px，1.6px 宽，左上白 α.18 → 中段 α.04 → 右下青 α.10 的斜向渐变。
4. 厚度带：内缩 4.0~7.5px **不画线**，让底色透出来——这段留白就是「材质截面」。
5. 内框 1px，内缩 7.5px：青色 α.26（领位）/ α.12（侧位）。
6. 内凹阴影：内缩 8.4 / 9.4 / 10.4px 三条 1px 黑线，α .18 / .09 / .05 递减。
另加角饰：左上、右上、右下三个直角（左下斜切处不镶边），内缩 7.5px、臂长 9px、1px 冰白 α.28；稀有度 C 档起，三处角各加一枚菱形（边长 2~3px，稀有度色 α.55）。

【卡面材质】从下到上六层，全部是纯色叠加：
① 铸面晕：圆心在左上 (32%, 20%)、半径 = 卡宽 ×.92 的径向渐变，稀有度色 α.07（F~D 用青色 α.05）→ 透明。
② 蚀刻线：−38° 斜线，间距 11px，1px 冰白 α.03。
③ 噪点：6px 网格里的静态点阵，冰白 α.035（固定随机种子，不能闪）。
④ 底缘内阴影：底部 22% 高度，黑 0 → α.42。
⑤ 卡面纵向明暗：青 α.05 在 38% 处最亮，72% 落下，底部叠黑 α.20。
⑥ 顶封条：顶边内侧 1px，冰白 α.14。

【版面】内边距 12 / 11 / 12 / 14，从上到下：
- 角标：mono 9.5px，字距 1.4，青色 #38E1FF（已放弃态转灰 #4B5E7C），如「MAIN · 05」。
- 印位 + 星轨（同一行）：左侧 34×38 的六边形印，六层结构——压印阴影（右下偏 1px 黑 α.55）、外六边（1px 稀有度色，F~E α.55 / D 起 α.90）、内底凹槽（内缩 2.5px 填充，稀有度色 α.10，C 起才有）、内六边（0.8px α.45，C 起）、内受光边（左上两段 1px 冰白 α.22）、外亮边（外扩 1px，B 起 α.30 / A·S α.55）。印中央是档位字母，Tektur/等宽 18px 800，稀有度色。
  印右下 26px 处放星轨：7 格 3×4px 竖刻度，间距 3.6px，点亮「档位+1」格（F=1 … S=7），未亮青色 α.12，亮格稀有度色；B 起亮格带 1.5px 模糊外辉。
- 名称：17px 700，冰白 #E9FBFF（已放弃转灰 #4B5E7C），最多 2 行。
- 点线规格表（仅可接态显示）：两行「时限 ⋯ 45 分钟」「验证 ⋯ 跑步 App 截图」，左标签 11px 灰 #4B5E7C，中间 1px 点阵（4px 间距、α.18），右值 12px 500 冰白，行高 15px。
- 术式徽记带（y≈156，高 34，横贯卡面）：中间一枚几何徽记（外环三段同心弧 + 六枚短刻 + 内核母题：力=三角/敏=双斜线/体=圆/智=方/知=眼/魅=菱形），稀有度色，α.5 左右；左端 7×7 四向短刻校验记号，右端 7.5px 序号（取角标尾号）。
- 报酬行（仅可接态，贴底左）：12px 等宽数字，如「4 · 5」，颜色雾蓝 #8FA6C4。
- 方印（已完成 / 待发布两态，贴底右 46px）：22×22 正方形双框（外 1px + 内缩 3px 的 1px），右下偏 1px 压印阴影；已完成 = 金底 #FBBF24 实心、旋转 −6°、深色字；待发布 = 青色线框、不旋转、字「待发布」；已放弃 = 红框 #FF4D5E 划掉、旋转 +8°。
- 批注（贴底左 8px，仅可接/执行中/已完成显示）：「» 接了就开计时。」11px 雾蓝 #8FA6C4。
- 执行中右下角计时：11px 等宽 700 青色，如「12:04」。

【状态线】贴底一条 2px，五态形状 + 颜色双编码：
- 可接：青色实线，两端渐隐 + 10px 辉光。
- 执行中：同一条线上加一个 12px 宽的亮青「光包」，从 0 走到 100%（1.6s 循环）。
- 已完成：金色 #FBBF24 实线，两端渐隐。
- 待发布：青色虚线（段 4 空 3 的 2px），α.33。
- 已放弃：灰 #9AA3B2 实线 α.27，整张卡再叠一层 #03060E α.55 压暗。

【内容】五张卡用同一张委托的不同状态，文案参考：
角标 MAIN · 05；名称「晨跑 45 分钟」；印位档位 B、星轨点亮 5 格；规格「45 分钟」「跑步 App 截图」；报酬「78 · 38」；批注「接了就开计时。」；执行中计时「12:04」。
另外四张同文案，只改状态：执行中（计时中）、已完成（方印「已完成」）、待发布（方印「待发布」）、已放弃（红框划掉）。

【硬性要求】
- 每张卡必须像素清晰、不糊；所有描边用 border/box-shadow/SVG，不用 canvas 也行，但六层卡边必须真的画出来（可以用多层 box-shadow inset 或嵌套 div/SVG）。
- 不许出现渐变模拟不了的「假材质」：噪点用 repeating-radial-gradient 或 SVG filter 也行，但必须静态。
- 不许用 emoji、不许加图标字体、不许引用外部图片。
- 页面背景 #03060E，卡间距 24px，可选加一行小字标注每张状态名（10px，雾蓝），但卡内不许出现状态文字（除方印）。
- 输出一个完整的 .html 文件，双击即可打开预览。
```

## 三、验收清单

- [ ] 打开页面可见 5 张 148×240 卡，背景深蓝，无其他页面元素
- [ ] 卡不透明，看不出任何「透底」；六层卡边肉眼可分（外青线、暗边、斜高光、内框、内凹阴影）
- [ ] 印位是六边形而不是色块；星轨是 7 格竖刻度，B 档亮 5 格
- [ ] 五态状态线形状不同：实线/光包/金线/虚线/灰线
- [ ] 已完成与待发布各有一枚方印；已放弃整张压暗
- [ ] 无 emoji、无外部资源、无 JS 依赖
