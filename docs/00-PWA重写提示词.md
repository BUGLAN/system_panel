## 提示词正文

你要把「宿主养成系统」从 Flutter App **完整重写成 PWA**。这是网文「系统流」风格的自我提升工具：用户是「宿主」，App 是毒舌但靠谱的系统娘「小祥」。用户立一个目标，她把目标拆成一单一单的「委托」；用户接单、按时完成、交照片证据，她验收、结算经验和奖励。

全程用中文：界面文案、代码注释、提交信息、给我的回复都写中文。

### 三、必须保留的产品机制（摘要，细节以源码为准）

**主流程**
- 开机 → 首启告知页 → 绑定仪式（输入目标 → 匹配类目 → 3 张访谈卡 → 拆出第一段）→ 大厅
- 大厅进主线 / 委托板 / 补给 / 档案；系统设置是抽屉；聊天面板随时可开
- 接单前先弹「接单前简报」（时长、证据要求、奖励、判负条件），点【开始计时】才开始计时
- 执行面板 → 交证据 →【提交任务】→ 结算；或者【认输】→ 失败页 → 补救单
- 动作区用词固定：【快照记录】【提交任务】【认输】

**目标与拆解**
- 11 个类目：奔跑 / 轻盈 / 力量 / 开口 / 上岸 / 早起 / 练技能 / 作品 / 上线 / 自信 / 变强，每类有专属的 3 张访谈卡和倾向的六维
- 滚动生成：每次只拆一个窗口（14 张；总数更少就按总数），走完再续拆下一段，进度按「第 x/总 天」显示；每段超过 12 张时分两路并行请求
- 第一段只出 E~C 档；之后按整条主线的进度走 E→D→C→B→A，只有最后一段出 S 档兑现单
- 拆解失败停在复核态：错误卡（按失败类型给标题和说明）+ 已答的访谈卡 + 【重试拆解】【换个说法】【改答案】【先跳过】，答案不清空
- 「先跳过」要记住输入过的目标，当天先发日常单；大厅主线卡位换成「待拆卡 + 重试拆解」
- 主线单只能接清单里第一张没完成的，后面的在委托板上锁住

**委托**
- 两种：计时单（倒计时，到点判负）和打卡单（不计时，当天内随时交）。拆解时由 LLM 标注是哪种，日常池里 6 条「整天型」是打卡单
- 档位 E~S（F 只用于补救残单），颜色读 `Ref.rank`
- 证据最多 3 张；拍照或从相册选

**经济（数值一个都不许改）**
- EXP：F0 / E1 / D2 / C4 / B6 / A8 / S10；晶核：F3 / E~C 5 / B7 / A10 / S20
- 升级曲线：`need(lv) = 12 + lv × 6`
- 结算乘区：暴击 ×2、双倍卡 ×2（可叠到 ×4）、补救单 ×0.5，补救单 EXP 保底 1；晶核吃暴击不吃双倍
- 暴击率：底 6% + 每张已校验证据 7% + 每张拿不准 / 未校验证据 4% + 连胜每天 1%（最多 10 天）+ 暴击芯片 25%，封顶 85%
- 评级：有判真证据 = A；只有拿不准 / 未校验 = B；没证据 = C；计时单用时不到目标的 1/4 降一档；暴击时 A 升 S；打卡单不看用时
- 累计 EXP 单独记一个只增不减的字段
- 道具：暴击芯片 45 / 双倍卡 60 / 护盾 90（2 级解锁）/ 补签券 30，效果见 `data/items.dart`
- 12 个称号，其中「口头巨人」是耻辱称号，摘不掉

**连胜与认输**
- 当天完成第一单时连胜 +1；只有一整天一单都没完成才断。认输**不断**连胜
- 主线单认输后，补救单**顶替**这一环（继承 goalId / planIndex，立刻入队）；交掉补救单就算这一环过关。补救单再认输，原单补回来
- 日常单认输按旧规则处理

**证据校验**
- 4 种状态：`verified` 判真 / `unsure` 拿不准，照收 / `unverified` 没校验成，照收 / `mismatch` 不符，拒收
- 判定不符：图撤出证据槽，小祥说明原因，槽下保留一行「上一张被拒：{原因}」，直到下一张入槽
- 选图后马上入槽，校验在后台跑；点【提交任务】时还有校验没回来，就等它们回来，最多等 20 秒，等不到的按未校验算
- 视觉校验超时 30 秒、超时不重试；交单那一刻证据封存，之后迟到的校验结论一律丢弃
- 照片发给模型前先压缩（长边不超过 1024px，JPEG）

**人设**
- `Persona.backstory` 原文一字不改，每次系统提示词都以它开头
- 四种语气（发布 / 结算 / 毒舌 / 追问）+ 表达铁律：每次不超过 3 句、不用 emoji、先吐槽再给一个可执行的下一步、句首带 `[情绪]` 标签（12 种）
- 台词按场合从台词库取，只在需要的时候才调 LLM

**护栏**
- 提示词里写明：减重每周不超过约 1 公斤；不出断食、催吐、泻药、脱水、极端热量缺口、带伤硬练这类任务；违法或伤人的目标不拆
- 目标和聊天发送前都先过本地自伤关键词闸门：命中就不发 LLM，小祥认真回一句，建议找身边的人或专业心理援助（不写热线号码）
- 输入上限：目标和访谈「自己写」50 字，聊天 200 字；拼音还在组字时不计字数，「确立目标」按钮置灰（用 `compositionstart` / `compositionend` 判断）

**存档**
- 自动存档：任何改动存档字段的操作完成后，合并到同一拍串行写入，不靠手动调保存
- 每次写盘前把上一份好档滚成备份；主档读坏就把原串另存为 corrupt，再从备份恢复
- 「重置存档」要清空：存档、备份、聊天记录、流水、长期记忆、证据照片；不清空 LLM 设置和同意记录
- 新增导出 / 导入存档（JSON 文件）：PWA 的数据只在这个浏览器里，这是用户唯一的备份手段
- 不需要迁移 Flutter 版的旧存档

### 四、视觉与动效

- 配色：底色 `#06050C`、主强调 acid `#D6FF3D`、cyan `#3BE8FF`、hot `#FF3B7A`、violet `#8F6BFF`、gold `#FFCC4D`、mint `#3DFFA8`；稀有度色谱照 `Ref.rank`。全部写成 CSS 变量，作为唯一令牌源
- 字体：显示字 / 数字用 Chakra Petch，中文正文用 Noto Sans SC，等宽用 JetBrains Mono，三套都自托管（`woff2` + `font-display: swap`）。中文字体做子集化，脚本在 `tools/fonts/`，要改成输出 `woff2`
- 动效参数（不许凭感觉改）：
  - 弹簧 stiffness 100 / damping 20，过冲到 1.08 再回弹
  - 亮帧：全屏白色、16% 透明度、脉冲 180ms，音效踩这一帧
  - EXP count-up：800ms、ease-out cubic；暴击：定格 200ms → CRIT 印章 scale 从 2.2 到 1 → 续滚双倍
  - 经验条：不跨级 520ms；跨级先涨满 360ms → 白闪 + 升级动效 → 归零 → 再涨到余额 420ms
  - 结算总时长 ≤ 1.6s；升级 ≤ 2s（同一天重复只播简版）；发布 ≤ 800ms
  - 失败：更短、更暗、更安静（亮度是成功的 1/3）
  - 打字机：标准每字 34ms
  - 禁用线性匀速；只动 `transform` / `opacity`
- 尊重 `prefers-reduced-motion`
- 等 LLM 的地方都要有加载态（拆解用分步进度卡），并且同时防连点

### 五、PWA 与浏览器适配

- 写好 manifest（应用名「宿主养成系统」，`display: standalone`，图标用 `brand/` 生成的），用 Service Worker 预缓存应用壳、字体和音效，断网也能打开、能看档案
- iOS 不会弹安装提示：首次访问时引导用户「添加到主屏幕」，说清楚不添加的话浏览器可能清掉数据；启动时调用 `navigator.storage.persist()`
- 适配安全区（`env(safe-area-inset-*)`）和 `100dvh`；键盘弹起时，输入框和 CTA 按钮要留在键盘上方
- 相机：`<input type="file" accept="image/*" capture="environment">`，另外给一个「从相册选」入口；证据照片以 Blob 存进 IndexedDB
- 音效：用 Web Audio 预解码后播放，第一次用户手势时解锁；iOS 上用 `navigator.audioSession.type = 'ambient'`（支持的版本才设），切到后台就停底噪。按下声由基础按钮组件自己负责，业务回调里只播结果声
- 震动：只在支持 `navigator.vibrate` 的设备上调用（iOS 不支持，静默跳过）
- 帧率：常驻循环动画在页面不可见时暂停

### 六、LLM 接入（用户自填 Key）

- 设置页填：端点（OpenAI 兼容 `/v1`）、API Key、文本模型、视觉模型、温度。提供【测试连接】按钮，并把失败原因分开报：没填 Key / 网络 / **CORS 被拦** / HTTP 4xx·5xx / 超时。浏览器直连时 CORS 是常见坑，提示里要写清楚
- 没配 Key 时，App 照常能用：拆解会走失败卡并引导去设置；证据按未校验照收；台词用本地台词库
- 重试规则：502 / 503 / 504 和断网重试 1 次，间隔 800ms；超时一律不重试
- 首启告知页保留简化版：说明目标、聊天和照片会发给你自己配置的模型服务商，同意后才发请求
