# 42 · 卡牌视觉方向探索 · 提示词生成器

> 状态：**待宿主过目**（本轮只出「生成提示词的提示词」，零 UI 改动）
> 用途：宿主没法用形容词说清「哪里不对」→ 用**批量气质提案**把「不好看」变成可挑选的选项

---

## 0 · 为什么不是「优化 100 轮」

宿主原提案：优化 100 轮、每轮打分、挑一条用。**机制上有两处会失效**，本文按修正版设计：

| 问题 | 现象 | 改法 |
|---|---|---|
| **审阅带宽** | 100 条里看到第 30 条判断力就掉了；且 LLM 同方向微调 100 次会收敛成几乎一样的文本 | **分阶段放宽度**：10 条拉开方向 → 挑 2~3 个 → 每个深挖 3~5 条 → 定稿。共 ~20 条 |
| **打分失真** | LLM 审同类产出有系统性偏差：分数集中在 7~8，没有区分度；且它不知道宿主品味 | **不做打分**，改两种结构化审查：① **反向审查**（指出这条最可能翻车的地方）② **成对比较**（A 与 B 在某个维度上谁强、差在哪一句） |

另一条必须说清的边界：**提示词定「气质」与「方向」，定不了「精确像素」**。
「六层卡边、厚度带 3px」写进提示词，生成出来可能是六层也可能糊成一层 —— 这中间差的 20 次调试只能在代码里做。
所以本生成器的产出**不是**可直接交付的设计稿，而是**决策辅助**。

---

## 1 · 载体约束（生成时必须注入，不可协商）

这些是**已经定稿的产品资产**，提示词只能在这套约束内找方向 —— 否则会做出「好看但不像这家产品」的东西。

### 1.1 锁定的视觉基因

| 项 | 值 | 出处 |
|---|---|---|
| 主题色 | 深蓝虚空 `#03060E` / `#0A0E1A` + 电光青 `#38E1FF` | `AGENTS.md` 已锁定 |
| 稀有度色谱 | F灰`#9AA3B2` E绿`#4ADE80` D蓝`#38BDF8` C紫`#A78BFA` B金`#FBBF24` A橙`#FB923C` S红`#FF4D5E` | 同上 |
| 品牌母题 | **六边核心 + 经验弧**（点顶正六边 + 沿六边顺时针的弧 + 弧头亮点 + 中央晶核） | `docs/23` §1，唯一真源 `brand/build.mjs` |
| 字体 | ShuHei（标题）/ FangYuan（正文）/ Tektur（数字）/ KodeMono（读数） | `design/tokens.dart` |
| 绘制方式 | **纯几何 CustomPainter**，无位图、无贴图 | 现状（换来的是任意分辨率不糊） |

### 1.2 三条红线（生成方案里出现即判废）

1. **不许真半透明 / 不许 blurred backdrop** —— 卡必须不透明，否则会透出后面的 Live2D（宿主三次反馈过「透明度太高」）。
2. **不许挡脸** —— 卡只许落在屏高 **45%~86%** 的安全带；她的脸在 20%~42%。
3. **不许引入第三种青、不许 emoji、不许新增色相** —— 稀有度色只出现在稀有度本身。

### 1.3 产品的叙事身份（这一条最常被忽略）

> 委托是**系统发布**给宿主的。牌面写编号、时限、验证方式、报酬 —— 它是一份**条款/契据**。
> 而系统是一个**冷感少女形态的拟人存在**，不是一块面板。

这决定了：好的方向应该让卡读作「她递给你的东西」，而不是「一个 App 的列表项」。

## 2 · 生成器本体（复制下面整段去用）

```text
你是这个产品的**游戏 UI 美术总监**。任务不是设计界面，而是产出**若干条互相拉开差异的视觉方向提案**，供宿主挑选。

## 产品背景
「宿主 SYSTEM」—— 网文系统流自我提升 App。玩家是「宿主」，App 是一个毒舌但靠谱、冷感少女形态的**系统**。
委托由系统发布：牌面上写着编号（MAIN · 05）、时限（45 分钟）、验证方式（跑步 App 截图）、报酬（EXP 4 / ◈5）。
它本质是一份**契据**，不是列表项。

## 已被锁定的视觉 DNA（你的提案必须活在这套约束内）
- 主题色：深蓝虚空 #03060E + 电光青 #38E1FF；稀有度七色谱（F灰→S红）
- 品牌母题：六边核心 + 经验弧（点顶正六边、沿边顺时针的弧、弧头亮点、中央晶核）
- 字体：ShuHei 标题 / FangYuan 正文 / Tektur 数字 / KodeMono 读数
- 绘制：纯几何（CustomPainter），无位图

## 三条红线（提案里出现即判废）
1. 不许真半透明、不许背景模糊（会透出后面的 Live2D）
2. 不许挡脸（卡只能出现在屏高 45%~86%）
3. 不许新增色相、不许 emoji、不许把稀有度色用在非稀有度处

## 你要产出什么
**10 条视觉方向提案**。每条的格式严格如下：

### N · 两条词的气质名
**一句话画面**：（把卡描述成一件**实体物件**，不要描述界面。例：「一块被铣床切过的冷铸铝牌，边缘有 0.3mm 倒角，右下角有一枚手打的钢印」）
**卡边**：（厚度怎么表达？几层？边缘有没有磨损/倒角/毛刺？）
**材质**：（表面是什么？粗糙还是光滑？有没有加工痕迹——铣痕/蚀刻/喷砂/氧化/纸纹？）
**稀有度怎么读**：（不靠颜色还能怎么分辨强弱？形状？格数？纹章？）
**状态怎么读**：（不靠文字，怎么一眼看出「可接/执行中/已完成/待发布/已放弃」？）
**主光**：（光从哪来？卡面哪里亮、哪里沉？）
**与角色的关系**：（这张卡怎么让人想到「是她递给你的」？）
**最可能翻车的点**：（诚实说 —— 在 148×220 的小尺寸上、纯代码绘制、深蓝底这三重限制下，这个方向哪一处最容易糊掉/做不出/变廉价？）
**落地成本**：低 / 中 / 高（并说一句为什么）

## 硬性要求
1. **10 条必须拉开维度，不是同一方向的微调**。请覆盖至少 6 个不同的「物质隐喻」大类，例如（不要照抄，自己发散）：
   冷铸金属 / 纸质档案卷宗 / 全息投影膜 / 生物发光 / 军用仪表面板 / 石刻碑铭 / 电路板蚀刻 / 玻璃负压管 / 皮革烙印 / 织物质感
2. **每条的气质名必须是两个词**，且能让人立刻想象出画面（「冷铸军械」可以，「现代科技感」不行）。
3. **禁止使用**这些空词：高级感、科技感、未来感、简约大气、精致、有质感、沉浸式。用具体的**工艺动词**替代（铣、蚀、铸、压、烙、锻、刻、锤）。
4. **最可能翻车的点不许写「无」**。每个方向都有它的死法，写出来才是诚实的提案。
5. 全部用中文。不要画图，不要写代码，只写文字提案。

## 输出前自检
- 10 条里有没有两条其实是同一个方向？→ 删掉一条重写
- 有没有一条违反了三条红线？→ 重写
- 每条的气质名，能不能让一个没看过这些文字的人，只凭名字就想象出画面？→ 不能就换
```

## 3 · 审查提示词（交给子代理，第二轮用）

这一条**取代打分**。理由是打分没有区分度，而「成对比较 + 反向审查」能产出宿主真正需要的信息。

```text
你是这套卡牌视觉的**外部审查者**。你不打分 —— 打分在同类产出之间没有区分度（会全落在 7~8 分）。

下面有 10 条视觉方向提案。请做三件事：

### 任务 A · 成对比较（找出真正的差异）
从 10 条里挑出**最接近的 3 对**，每对回答：
- 这两条在哪个维度上是同一个东西？（材质？光照？信息编码方式？）
- 如果只能留一条，留哪条、为什么？（用一句话说清判据，不要用「更好看」）

### 任务 B · 反向审查（每条的死法）
逐条回答：**如果按这条提案去做，最可能先在哪一步翻车？**
要考虑三重限制：
- 尺寸：领位卡只有 **148×220**（约 3 倍屏 = 444×660 物理像素）
- 实现：**纯 CustomPainter 几何**，没有位图、没有模糊背景
- 环境：深蓝底 `#03060E`，低亮度下 α < .05 的东西**等于不存在**

每条给一句具体的、可验证的失败场景（例：「铣痕在 148 宽下会退化成噪点，看起来像脏了」）。

### 任务 C · 挑出三条最值得做的
并给出一句理由：它为什么在「差异化」与「做得出来」之间平衡得最好。

不要给总分。不要排总榜。不要写鼓励性评语。
```

## 4 · 宿主怎么用（三步）

| 步 | 做什么 | 产出 | 耗时 |
|---|---|---|---|
| 1 | 跑 §2 生成器 → 得 10 条方向 | 10 个「两个词的气质名 + 一句话画面」 | 一次生成 |
| 2 | 扫一眼，挑 **2~3 个**想深挖的方向 | 你的选择 | 30 秒 |
| 3 | 对选中的方向，让生成器**只针对它**再出 3~5 条变体（把「10 条必须拉开」改成「同一方向内做 3~5 档浓度：克制 / 标准 / 浓烈」） | 细化版 | 一次生成 |
| 4 | 定稿 → 我把它翻译成具体代码改动 → 截图验证 | 真机的样子 | 按成本 |

**关键**：第 2 步只看「气质名 + 一句话画面」，不要读完整提案。那两行就是给你做选择的。

## 5 · 一条必须写在前面的实话

**提示词能定气质，定不了像素。**

举例：「六层卡边 + 3px 厚度带」这句话，生成出来可能是六层，也可能糊成一层 —— 中间差的 20 次微调只能在代码里做。
所以本生成器的正确用途是：**在动手改代码之前，先确认往哪走**。它取代不了「写 → 截图 → 看 → 改」那个循环，但它能让那个循环少走弯。

另外：**最终落地必须回到本文 §1 的约束内**。提示词产出的方向如果跟品牌基因冲突，一律以品牌基因为准 —— 否则会做出「好看但不像这家产品」的界面，那是更贵的失败。
