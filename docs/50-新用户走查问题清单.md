## C · 困难问题（规则 / 算法 / 根因未明 / 需拍板）

- [ ] C1 「半年减重」拆出 180 单、全 E、奖励全「意志」—— 与 docs/06「5~8 环主线链」冲突。
  - 2026-11-05 定案：滚动生成（每次只拆一个窗口，做完再拆下一批，进度仍按总天数显示）；六维改各类目权重（运动类加「力」=体质，早起/习惯类留「体」=意志），存档键与显示名不动
- [ ] C2 访谈题套错类目：学吉他被问「一周能创作几次 / 有作品 / 一件完整小作品」。
  - 2026-11-05 定案：新增「练技能」类目（乐器/绘画/舞蹈/书法…），访谈题按「练」来问
- [ ] C3 计时模型不适合全天类任务（「空腹上秤」5 分钟倒计时、「三餐拍照」12 分钟）—— 需区分「计时」与「打卡」任务类型（docs/16）。
  - 2026-11-05 定案：新增「打卡」类任务（不计时、随时传证据提交），拆解时由 LLM 标注计时/打卡
- [ ] C4 证据校验尺度：体重秤任务上传花的照片被收下并评 C —— 遵循 docs/04「信任不查岗」还是真校验，需拍板。
  - 2026-11-05 定案：**不符就拒收，要求重传**（LLM 判定不符 → 不入槽 + 她说明原因；拿不准 / 没校验成仍收下）
- [ ] C5 「暂时跳过」丢弃已输入目标且无兜底（模板兜底是刻意删除的）—— 上游不可用时新用户第一天做什么。
  - 2026-11-05 定案：保留输入过的目标 + 大厅「一键重试拆解」+ 先发当天日常单
- [ ] C6 连胜规则：一次认输清零「连胜天数」，与 docs/05「前 10 单必胜」如何协调。
  - 2026-11-05 定案：维持现状 —— 认输不断连胜，只有一整天一单没完成才断
- [ ] C7 LLM 延迟：拆解 35s+，单张图预校验约 18s。
  - 2026-11-05 定案：不换模型；证据改后台异步校验、提交时出结果；拆解提速随 C1 滚动生成
- [ ] C8 聊天面板「查状态」后约 10s 自行关闭，小祥无回复 —— 根因未查。
  - 不需拍板：代码只有 ✕ / 点背景 / 返回键三条关闭路径，待复现定位
- [ ] C9 待确认是否预期：大厅无 Live2D 只有眼睛徽标；主强调色实际为荧光黄绿（AGENTS 锁定电光青 #38E1FF）；冷启动白屏约 5s（debug，release 未测）。
  - 2026-11-05：配色 / 字体 / 视觉基准已定案 —— 以当前 v3（`design/ref.dart` + `宿主养成系统_重设计.html`）为准，已写进 AGENTS.md；Live2D 是 2026-10-27（`6f10de1`）有意移除。仍待确认：冷启动白屏约 5s（需 release 实测）
  - 2026-11-05：宿主后续自行处理。现象：debug 包冷启动约 5s 白屏后才出启动页；iOS 模拟器跑不了 release，需在真机或 MuMu 上用 release 包实测再定
