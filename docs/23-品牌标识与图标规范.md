# 23 · 品牌标识与图标规范（宿主 SYSTEM）

> 状态：v1 已落地（2026-10-11）。唯一真源 `brand/build.mjs`；本文档说"为什么"，

## 1. 标识是什么

**「六边核心 + 经验弧」**：点顶正六边框 + 沿六边顺时针走的经验弧 + 弧头亮点 + 中央晶核。

图形不是凭空画的，每个零件都来自 App 里已有的视觉原子（宿主看得见摸得着的那些）：

| 零件 | 出处 |
| --- | --- |
| 点顶正六边 | 底栏「档案」键的字形（`index.html` dock 图标 `M12 3l7.8 4.5v9L12 21l-7.8-4.5v-9z`，正六边、顶点朝上、外接半径 R），金币字形同族 |
| 沿六边走的弧 | 等级牌上的经验环（HUD `#lvArc` / v9 面板牌「沿六边轮廓走的经验弧」），从顶部顶点顺时针点亮 |
| 弧头亮点 | 经验条尾部的"当前位置"，也压着「叮。」那一声的脉冲点 |
| 中央晶核 | 档案六边牌的"牌芯"，即宿主本人——系统围着它转 |

一句话：**系统的框架围着宿主的核，弧走到哪，宿主就练到哪。**

### 1.1 几何（512 母版画布）

- 六边外接半径 **R = 172**，圆心 (256,256)，顶点朝上；周长 6R = 1032（与原型等级牌"周长 186.4"同一算法，只是尺寸不同）。
- **弧长 4.5 / 6 边**：从顶点 V0 顺时针点亮到左边正中（九点位置）。落选方案见 `_sheet.png`：
  - 4/6 收在顶点 → 亮点和角粘连，读不出"游标"；
  - 5/6 只剩一条暗轨 → 小尺寸会被看成圆；
  - 空心晶核 → 像六角螺母（五金件），弃。
- 线宽三档：母版 22 / 图标切 30 / ≤96px 粗版 40（小尺寸必须加粗，缩到 20px 仍立得住）。
- 晶核 R=60（图标切）/ 64（粗版），实心、青白渐变；弧头亮点 r=21/28，屏显白。
- 辉光只上母版与 ≥144px 图标切；小尺寸一律无辉光（糊）。

### 1.2 色板（沿用锁定色板，一色未加）

`#03060E` 虚空（底）· `#0B1A36` 面板蓝（底板渐变中段）· `#38E1FF` 电光青（唯一强调）·
`#EAF7FF` 屏显白（晶核顶/亮点）。弧的渐变端 `#1E9BFF`/`#B6F7FF` 是电光青的明暗两档，
不引入新色相。青色标识**只上深底**；浅底一律换单色剪影（NAVY 或 ICE）。

### 1.3 字标（组合字）

- 中文 **宿主** ＝ 阿里妈妈数黑体 ShuHei Bold（App 标题同款）；
- 拉丁 **SYSTEM** ＝ Tektur，全大写 +0.35em 字距（设计系统"拉丁状态字 0.2em"规则的加宽版）；
- 横排：标识 + 3px 青色细分隔线 + 字标两行左对齐；竖排：标识居中在上。
- 最小尺寸：字标横排 96px 宽以下就别用了，直接用标识。

## 2. 图标

- **1024 母版**：虚空→面板蓝径向底 + 1/16 网格（径向渐隐）+ 一圈召唤阵细环（只在大尺寸可见）+ 标识（六边外接半径 366 ≈ 71% 边长）+ 四角压暗。
- **Android**：旧版 `ic_launcher` 48–192（圆角 17% 自带、≤96 用粗版）；**自适应图标**三层——背景=满幅底板、前景=标识（六边外接半径 28dp，实心最远半径 31dp，落在 66dp 安全圆内有余量）、单色层=全白剪影（Android 13+ 主题图标）；`mipmap-anydpi-v26/ic_launcher.xml` 已建，API 25 及以下自动回落旧图。
- **iOS**：Contents.json 19 格全部重生成，文件名未动；**已去 alpha**（App Store 硬要求）；≤120px 用粗版。深色/着色变体（iOS 18 appearances）暂不做，等真机验证后再加。
- **原型 favicon**：`favicon.svg` + 16/32/48 PNG + `apple-touch-icon.png`（180，圆角已烘焙），`index.html` 的 `<link rel="icon">` 从 `data:,` 空占位换成真图标。

## 3. 用法与禁例

- **禁**：给标识加投影/描边/渐变背景之外的任何修饰；把晶核换成字母或表情；把弧改成圆弧（那就不是"沿六边走的经验环"了）；拉伸、旋转、加描边字。
- **禁**：青色标识直接印在白底上（对比不够）——浅底用 `logo-mark-mono` 的单色剪影。
- **留白**：标识四周至少留 1/6 标识高度的空（六边外接半径的 1/3）。
- **唯一改法**：改 `brand/build.mjs` 参数 → `node brand/build.mjs` → 同步本文档。手改生成物会在下一次重生成时被覆盖。

## 4. 尚未应用（宿主指定本轮不做）

- App 内页面（开机页「宿 主 · 系 统」旁、设置面板头）不放标识——宿主明确只要"App 启动图标 + 原型 favicon"。
- 应用显示名维持 `system_panel` / `System Panel` 未改。
- Flutter 侧将来要用时：把 `brand/logo/*.svg` 拷进 `app/assets/brand/` 并在 pubspec 声明（`flutter_svg` 已在依赖里）。
