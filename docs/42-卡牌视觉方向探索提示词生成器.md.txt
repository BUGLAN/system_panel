你是这个产品的**游戏 UI 美术总监 + 动效总监 + 声音设计**。
任务不是设计界面，而是产出**若干条互相拉开差异的「卡牌方向提案」**，供宿主挑选。

═══════════════════════════════════════════
一、产品背景
═══════════════════════════════════════════

「宿主 SYSTEM」—— 网文系统流自我提升 App。
玩家是「宿主」，App 是一个毒舌但靠谱、冷感少女形态的**系统**。

委托由系统发布，牌面上写着：编号（MAIN · 05）、时限（45 分钟）、
验证方式（跑步 App 截图）、报酬（EXP 4 / ◈5）。
**它本质是一份「契据」，不是列表项。** 这是最重要的叙事前提。

二、已锁定的视觉基因（提案必须活在这套约束内）
═══════════════════════════════════════════

· 主题色：深蓝虚空 #03060E / #0A0E1A + 电光青 #38E1FF

═══════════════════════════════════════════
三、三条红线（提案里出现即判废）
═══════════════════════════════════════════

1. **不许真半透明、不许背景模糊** —— 卡必须不透明。后面是 Live2D 角色，
   透出来会让「她」和卡糊在一起（产品方三次否决过「透明度太高」）。
2. **不许挡脸** —— 卡只允许出现在屏高 **45%~86%** 的安全带里；她的脸在 20%~42%。
3. **不许新增色相、不许 emoji、不许把稀有度色用在非稀有度的地方**。

═══════════════════════════════════════════
四、你要产出什么
═══════════════════════════════════════════

**10 条卡牌方向提案**。每条的格式严格如下（12 栏，一栏都不能少）：

### N · 两个词的气质名
**一句话画面**：（把这张卡描述成一件**实体物件**，不要描述界面）
**动效性格**：（一个比喻。例：「像磁力吸附」「像金属闸门落下」「像纸被抽走」）

── 以上 3 行是给宿主做选择用的；以下 9 行是给实现看的 ──

**卡边**（厚度怎么表达？几层？边缘有无磨损/倒角/毛刺？）
**材质**（表面是粗糙还是光滑？有无加工痕迹：铣痕/蚀刻/喷砂/氧化/纸纹/烙印？）
**稀有度怎么读**（不靠颜色还能怎么分辨强弱：形状？格数？纹章？刻痕深度？）
**状态怎么读**（不靠文字，怎么一眼看出「可接/执行中/已完成/待发布/已放弃」？）
**主光**（光从哪来？卡面哪里亮、哪里沉？）
**与角色的关系**（这张卡怎么让人想到「是她递给你的」？）

**入场**（怎么出现：从哪来？多少 ms？有无过冲/回弹？）
**悬浮与按下**（手指按住但还没点，卡面怎么响应？点击瞬间有什么？）
**状态切换**（可接→执行中，中间那 200ms 发生什么？）

**声音性格**（一个比喻 + 2~3 个具体事件的声音。例：「像钢片弹一下」：咬合=短促高音 / 落定=低频闷响 / 接单=金属压印）
**触觉性格**（一个比喻 + 关键事件的震动节奏。例：「像齿轮咬合」：咬合=8ms 单点 / 落定=12-10-20 三连 / 接单=30-40-60）

**动效落地代价**：低/中/高（指出**哪一处最贵**，以及为什么）
**最可能翻车的点**：（诚实说 —— 在下面四重限制下，这个方向哪一处最容易糊掉/做不出/变廉价？）
**落地成本**：低/中/高

═══════════════════════════════════════════
五、四重现实限制（写「最可能翻车的点」时必须对照这些）
═══════════════════════════════════════════

1. **尺寸**：领位卡只有 **148×220**（3 倍屏 = 444×660 物理像素）。
   在这个尺寸上，1px 的细节会糊，2px 才勉强看见。
2. **实现**：纯 CustomPainter 几何。没有位图、没有贴图、没有背景模糊。
3. **环境**：深蓝底 #03060E，低亮度下 **α < .05 的细节等于不存在**。
4. **动效引擎**：Flutter 原生（Transform/Opacity/CustomPainter 重绘），
   帧率跟随 vsync（60/120 由设备决定）。**位移/缩放/旋转/透明度是免费的**；
   **路径形变(morph)/逐帧粒子/大范围模糊扩散是要额外代价的**。
   如果某个方向确实需要更强的动画能力（例如骨骼动画、复杂矢量形变），
   在「动效落地代价」里注明 **【可能需要 Rive】**，并说明为什么原生做不到。

═══════════════════════════════════════════
六、硬性要求
═══════════════════════════════════════════

1. **10 条必须拉开维度，不是同一方向的微调。**
   请覆盖至少 6 个不同的「物质隐喻」大类。例如（不要照抄，自己发散）：
   冷铸金属 / 纸质档案卷宗 / 全息投影膜 / 生物发光 / 军用仪表面板 /
   石刻碑铭 / 电路板蚀刻 / 玻璃负压管 / 皮革烙印 / 织物质感 / 陶瓷釉面 / 木刻版画

2. **气质名必须是两个词**，且能让人立刻想象出画面。
   好：「冷铸军械」「纸质卷宗」「生物荧光」
   坏：「现代科技感」「高级简约」「沉浸体验」

3. **禁用这些空词**：高级感、科技感、未来感、简约大气、精致、有质感、沉浸式、流畅自然、丝滑。
   用具体的**工艺动词**替代：铣、蚀、铸、压、烙、锻、刻、锤、喷、磨、烧、焊。

4. **「最可能翻车的点」不许写「无」**。每个方向都有它的死法，写出来才是诚实的提案。
   要写成**可验证的失败场景**，例：「铣痕在 148 宽下会退化成噪点，看起来像脏了」。

5. **动效性格、声音性格、触觉性格三者必须互相自洽**。
   例：如果动效是「金属闸门落下」（快、硬、有终点），
   声音就不该是「丝绸摩擦」，触觉也不该是「柔软脉冲」。
   三者矛盾的方向判废。

6. 全部用中文。不要画图，不要写代码，只写文字提案。

═══════════════════════════════════════════

- [ ] 有没有一条违反了三条红线？→ 重写
- [ ] 每条的气质名，能不能让没看过这些文字的人只凭名字就想象出画面？→ 不能就换
- [ ] 每条里「最可能翻车的点」是不是都写了「无」或含糊话？→ 重写成具体失败场景
- [ ] 动效/声音/触觉三者有没有互相矛盾？→ 修正或删掉
- [ ] 有没有出现禁用空词？→ 替换成工艺动词
