# 48 · UI 重设计 v2：Live2D 舞台化 + 游戏 HUD + 卡片材质

> 2026-10-25 · 分支 `feat/ui-refactor` · 表现层重构，**业务逻辑 / 数据流 / 公开 API / widget key / 几何尺寸不变**（735 条旧测试原样通过）。

## 1. 设计方向

| 维度 | 方向 |
|---|---|
| 视觉语言 | 「深空舞台 + 精密仪表」：深墨色分四层（`Pal.ink0~3`），电光青只给**可交互 / 进行中**，金色只给**货币与兑现**，稀有度色只给**卡**。文字四级（`Pal.text1~4`）。切角语言统一（CTA / 菜单铭牌 / 卡角标）。 |
| Live2D 舞台化 | 她不再「站在黑底上」，而是站在一座**被灯照着的舞台**：`StageAura` 在她身后画顶光束、背光晕、暖色轮廓光、地台光环（带刻度与扫描弧）、浮尘与暗角；全部锚定在 `StageAnchors`（发顶 / 胸口 / 脚底）经 `Cam.toScreen` 换算，跟镜头走。情绪（`StageMood`）改变光色，戳她 / 发布委托时打一次**脉冲**（光环扩散 + 背光闪亮）。UI 退到舞台边缘：背景大字减半、补给不重复印余额、档案面板上沿羽化溶进舞台。 |
| 动效原则 | ① 按下 0ms（跟手）② 抬起弹回（`Ease.pop` 带过冲）③ 换位 / 进场用弹簧（`SpringSpec`）④ 一次性动效必须收口——**禁止无限循环 AnimationController**（费电，且 `pumpAndSettle` 永不安定）；唯一的常驻循环是舞台光呼吸，且只在富效果档、限 30fps。 |
| 声音策略 | 「声音只给已发生的事」：**按下不出声只震**；过程音（聚焦 / 翻牌 / 开合）降音量 + 节流；落定音（压印 / 兑现 / 升级）满音量。规则表 `SoundRule.cues`，调用 `Sfx.cue(name)`。总开关沿用 `sound`，新增三档**界面音量**（低 / 中 / 高）。 |

## 2. Token（`lib/design/tokens.dart`，只增不改）

- 颜色 `Pal`：墨色层级、舞台光（halo / rim / dais）、金（= 稀有度 B 金，**不新增主题色**）、文字四级、全息箔色带、情绪光色 `moodHalo`
- 间距 `Space`（4 点栅格）、圆角 `Radii`、阴影 `Elev`（low / high / glow(color)）
- 曲线 `Ease`（enter / exit / pop / glide / breathe）、弹簧 `SpringSpec`（press / tilt / table / camera）
- 声音 `SoundRule` + `cues`
- 旧 `C` / `F` / `Motion` 数值未动

## 3. 卡片材质 v2（`GlassPainter`）

扫描纹 → 对角高光（跟手）→ **全息箔**（screen 混合彩虹斜带，领位专属，换领位时扫一次）→ 镜面柔光 → 顶边受光棱 → 内阴影 → 底边稀有度反光 → 渐变边缘光（白 → 稀有度色）→ 三枚 L 形角标。全部单次 `drawRect / drawPath`，无 blur、无 saveLayer。

牌桌（`card_table.dart`）：
- **真 3D 牌扇**：侧牌绕 Y 轴朝内偏航（透视 0.0011），领位拖拽时随手势偏航
- **跟手倾斜 + 镜面眩光**：按住时卡片朝指尖下压（≤7°），一团 screen 混合的柔光跟着指尖；抬手弹簧回正；拖滑轨时立即回正。只重绘这一张牌（`RepaintBoundary`）
- **领位光池**：领位脚下一团稀有度色椭圆辉光 + 台面反光线（与她脚下的地台光同一套光源语言）

## 4. HUD / 按键

- `GameButton`（`widgets/game_button.dart`）：有厚度的实体键——底座 + 面（按下下沉 3px）、竖向渐变、受光棱、斜纹刻槽、›››、外辉、一次性扫光；次键为暗玻璃 + 渐变描边。主线页【去执行】/【换目标】已替换（key、高 56、M-21 位置不变）
- 等级环：暗色表盘 + 36 格刻度 + 渐变进度弧 + 弧头光点
- 货币：金色胶囊（全 App 唯一的暖色读数）
- 菜单：斜切小铭牌
- 侧键：玻璃球（径向渐变 + 渐变边缘光 + 月牙高光 + 落地阴影），抬起 `Ease.pop` 回弹；进度弧加轨道与辉光

## 5. 画质档（性能）

`Fidelity.of(context)` → `FxLevel`：

| 档 | 条件 | 行为 |
|---|---|---|
| rich | 默认 | 舞台光逐帧呼吸（30fps）、浮尘、全息箔、CTA 外辉与扫光、跟手倾斜 |
| lite | 设置 →「舞台特效：省电」 | 舞台光静态一帧（脉冲仍一次性播放）、无箔、无外辉 / 扫光 |
| still | 系统「减弱动态」 | 静态、无倾斜、无下沉，只保留压暗反馈 |

纪律：Live2D 平台视图仍不套 `Opacity`、不加 blur；舞台光层在她**身后**；卡片保持不透明。
