## 2 · 设计立场（四条骨头）

1. **选择是两个人的事。** 牌从她胸口的光束里出来（锚点 `StageAnchors.chest` = (195, 375.67)）；你选中的牌飞向「你这边」（执行台 / 名牌 / 档案），没选的翻回牌背、沿光束收回她袖中。菜单是单向的，牌局有来有回——这一来一回就是全部仪式感，不需要任何新机制支撑。
2. **牌是实物。** 有重量（弹簧过冲 ≤1.08 才停稳）、有姿态（侧牌外倾，像被手指捻开）、有正反（背面先到，正面要「翻」过来）、有去处（落定后飞向归宿，不凭空消失）。所有位移只走 Transform / Opacity，像真实物体一样不引起周围重排。
3. **光是语言，不是装饰。** 同一时刻**全场只有一张牌发光——领位**。稀有度色只出现在三个位置：牌左侧 3px 竖条、印位大字母、揭示前 120ms 的牌背「预辉」。其余一切保持青色。光回答的问题是「现在轮到它」，不是「这里好看」。
4. **期待先于揭晓。** 揭示顺序 = 稀有度从低到高，最稀有的**最后翻**；每翻一张音高升 2 半音。信息不提前给完，但给到「能做决定」为止：领位信息全开、侧牌摘要、长按审视翻看背面明细。

### 4.1 牌面九区（L 档 208 × 292 基准）

+--------------------------------\

### 4.2 尺寸档（不新增第 23 号之外的几何）

| 档 | 尺寸 | 用在 |
|---|---|---|
| L 大牌 | 208 × 292 | 扇阵（命运级选择）、对局单牌 |
| S 小牌 | 86 × 112 | 台阵（**23 甲已落地，原样收编**） |

侧位**不换尺寸，只做 Transform 缩放**（扇阵 .82；台阵沿用现值 .88）——只动 Transform / Opacity，不触发重排。所有几何数字都是首版参数，以样机调出来的为准。

### 4.3 领位全开，侧牌摘要

缩放会吃字号：扇阵侧位的规则行 13 × .82 = 10.7px，不达 13px 下限。所以**不同位置露不同的区**——既守住可读性，桌面也不乱：

| 区 | 领位 | 侧位（×.82） | 审视（长按，×1.25） |
|---|---|---|---|
| ① ② ③ ⑨ | ✓ | ✓ | ✓ |
| ④ 名称 | ✓ | 单行截断（18 × .82 = 14.8px ✓） | ✓ |
| ⑤ 规则行 | ✓ | — | ✓ + 完整规则 |
| ⑥ 报酬条 | ✓ | 只留数字 | ✓ |
| ⑦ 代价条 | ✓ | 只留图标 | ✓ |
| ⑧ 批注 | ✓ | — | ✓ + 完整一段 |
| 背面明细 | — | — | 这张牌的来龙去脉（现有数据的呈现，如「已持有 ×2」「上次：完成」） |

### 4.4 牌背与预辉

- **牌背**：`C.abyss → C.navy` 竖向渐变；32px 网格（`C.line2`）；中央六边徽记（`C.blue` α.5）；底部 KodeMono 编号 `NO.0427`（本地单调计数，纯装饰，不入档、不作任何机制锚）。
- **扫描线**：每 4s 掠过一次（减弱动态或「全息描边」关时取消）。
- **预辉**：揭示前 **120ms**，牌背四边按稀有度染色——只有带稀有度的牌才有。选 120ms 是因为人眼对边缘颜色变化比对中央图形早一拍感知：**先给边，不给内容**，期待感就长在这一拍上。这是「先期待，后揭晓」的物理实现。

## 5 · 牌阵：一个旗舰 + 两个已收编

三阵共享同一条手感法则（23 号宿主点名关键词）：**任一时刻恰有一个领位；领位抬起，邻位按距离双向让位**。

### 5.1 扇 · 旗舰牌阵（命运级选择，2~4 张）

| 位 | 缩放 | 横移 | 纵移 | 旋转 | 不透明 |
|---|---|---|---|---|---|
| 领位 | 1.00 | 0 | −16 | 0° | 1.0 |
| ±1 | .82 | ±104 | +18 | ∓6°（向外倾） | .62 |
| ±2（仅 4 张） | .70 | ±178（露半张） | +40 | ∓11° | .40 |

- **转轴在牌底中心**——像手里捏着一把牌，不是桌上平铺。侧牌外侧上角可以出屏（露边是质感），但侧牌可点区（牌心 60%）必须完整在屏内。
- **让位是双向的**：领位向前抢（抬起 + 辉光），邻位向后缩（下沉 + 外倾 + 横向外推 3px）——领位像从整叠里被「抽出来」，不是各自独立缩放。
- **换领位**：整组沿弧滑动，弹簧用真源 `Spring(k:120, ζ:.9)`（`app/lib/stage/spring.dart`；25 号 G3 指出它还没有正式用户，扇阵是它的第一个）。

### 5.2 台 · 物件台（= 23 甲，原样收编，零返工）

卡 86 × 112、间距 8、stride 94、侧卡缩放 .88、名称 15px（等效 13.2px，测试钉住 ≥13）、侧卡向外旋开 ±4° 并压暗。**用在**：使用道具；补给（货架变体：四张物件牌挂一条发光挂轨，牌下吊六边金币价签，买不起 = 灰 + 价签红描边 + 小锁）。

### 5.3 轨 · 铭牌轨（= 23 乙，原样收编，零返工）

横版斜切薄牌 268 × 58；领位左对齐 + 抬起 −8 + 左侧 3px 青竖条；其余向右阶梯缩进 14px × 序数、下沉 6、压暗 .5；**不缩放**（保正文可读）。**竖排变体**（访谈答案可两行）：300 × 64 竖叠、间距 10，领位向左探出 12px + 青竖条。**用在**：回应、访谈答案、一切对白式选择。

### 5.4 降级矩阵

| 条件 | 降级 |
|---|---|
| 系统字号 ≥ 1.3 | 扇 → 竖排轨阵（保正文 ≥13px 且不裁字） |
| 屏宽 < 360 | 扇侧位横移按比例收窄，侧牌只留印位与名称 |
| 减弱动态 | 无飞行 / 翻面 / 旋转 / 扫描线 / 全息箔；领位只靠描边 + 辉光 + 状态线；切换 120ms 淡入淡出 |
| 「全息描边」关（低端机） | 关扫描线、全息箔、背景模糊（改 α.94 纯色底） |

## 6 · 六拍编排（动效核心）

### 6.1 六拍是节奏语法，不是一个固定动画

同一副骨架，按分量伸缩——这就是「轻场景不用大仪式」的解法：

| 拍 | S 大牌桌 | A 正牌 | B 轻牌 | 微牌 |
|---|---|---|---|---|
| 召唤 | 她亮相 `present` + 「叮！」 + veil .6 | 「叮。」 + veil .6 | 她那句话本身 | 无 |
| 发牌 | 光束 + 弹出/掉落 + 全息箔 | 光束 + 弧线发牌 | 自句尾滑出 | 原位亮起 |
| 揭示 | 逐张翻面 + 预辉 + 音高阶梯 | 同左 | 无（正面即达） | 无 |
| 端详 | 领位 / 审视 / 批注 | 同左 | 领位 | 领位即预览 |
| 落定 | 点牌 + 压印 + 白闪 | 点牌 + 压印 | 点领位左滑出 | 点即生效 |
| 余波 | 飞向归宿 + 她回嘴 + 收牌 | 同左 | 化为一行字幕回执 | 状态线实心 |

### 6.2 状态机

```
SUMMON -> DEAL -> REVEAL -> BROWSE <-> INSPECT
   |                        ^  |
   +--- tap anywhere: skip --+  +--> (A/S) ARMED --release early--> BROWSE
                               |            |
                               |            v
                               |         COMMIT -> AFTERMATH -> EXIT
                               |
                               +--> (B/C) COMMIT -> AFTERMATH -> EXIT
                               |
                               +--> exit plate / back key --> FOLD -> EXIT
```

召唤→揭示：整桌 `IgnorePointer`，只留一层「点按跳过」。端详：唯一允许自由停留的状态，停多久都无惩罚。落定：瞬间锁桌（沿用 `choices.dart` `_locked` 语义：一下 = 一声 + 一震）。

### 6.3 A 级逐帧：叮 → 可选 ≤ 800ms（对齐「发布 ≤800ms」）

| t (ms) | 事件 | 画面 | 声 | 震 |
|---|---|---|---|---|
| 0 | 召唤 | veil 压暗到 .6（300ms `kOut`）；顶部经验条不动 | `publish`（叮） | `publish` |
| 0+ | 字幕 | 打字机「叮。请宿主三选一。」（34ms/字） | — | — |
| 60 | 光束 | 胸口锚点向牌桌中心打一道 2px 青线（120ms） | — | — |
| 140 / 200 / 260 | 发牌 ×3 | 牌背从光束末端弹出、带初速方向的旋转（像被甩出），沿弧飞到扇位，360ms 弹簧，过冲 ≤1.08，落位时旋转归零（一圈「捻牌」） | `deal` ×3，逐张升调 | `tap` ×3 |
| 480 | 预辉 | 牌背四边按稀有度染色 120ms | — | — |
| 560 / 620 / 680 | 揭示 | **按稀有度从低到高**翻面（rotateY 200ms，牌底中心为轴，转到 90° 时换面；≥B 的牌换面帧加一次牌面局部亮闪） | `flip`（≥B 用 `flip_rare`），逐张升 2 半音 | `choose` |
| 760 | 领位 | 中位抬起 + 外辉；侧位双向让位 | `rung` | — |
| 800 | 可选 | 打开命中区 | — | — |

节奏注解：揭示间隔 60ms——少于 50mm 听成连续噪声，多于 80ms 变拖沓，60ms 恰好是「能数出来」的间隔。

**落定段**（点领位后，≈700ms；失败语境见 §6.6）：

| t (ms) | 事件 |
|---|---|
| 0 | **只闪这张牌**的局部白闪 16% / 180ms（不闪全屏）+ `seal` 音 + `seal` 震 |
| 0~260 | 压印「接 / 用 / 定」：scale 2.2 → 1、rotate −14° → −6°，弹簧——与结算印章同一个动词；投影向右下偏 2px |
| 260~700 | 领位牌收成一道光痕飞向归宿：日常 → 执行台；称号 → 档案名牌；道具 → 当前委托的牌角 |
| 260~560 | 侧牌翻回牌背，沿原弧收回光束（发牌的**反向倒放、时长打七折**——余波必须短于正片），光束熄灭 |
| 700 | 她回嘴一句（§8），退场 |

### 6.4 S 级：六拍全奏（叮 → 可选 ≤ 2.0s，对齐「升级 ≤2s」）

在 A 级之上加三件：① 她先做 `present` 亮相再发牌；② 牌面全息箔：揭示时一道斜向流光扫过一次（1.6s，青 → `C.rS` → 青，α.18），之后每 6s 闲置扫一次；③ 「叮！」是全 App 唯一允许感叹号的地方。适用于现存的重时刻（重置存档 §13-12 等）；同日重复只播简版（发牌与揭示合并为 240ms 正面落位）。

### 6.5 B 级：三拍压缩（≤ 350ms）

召唤 = 她那句台词本身；发牌 = 铭牌自句尾滑出（240ms `kOut`，错峰 0 / 60ms）；落定 = 领位牌向左滑出（−28px + 淡出）+ `choose` + 8ms 震。**23 乙已实现这套，本文只是把它命名为「六拍的压缩形」**——全 App 的选择从此是同一族节奏。

### 6.6 失败语境：另一种语气（≤ 300ms）

覆盖认输 / 补救等一切失败语境中的选择：不翻面、不飞行、不粒子、不白闪；牌原位淡入并上浮 12px（300ms）；亮度为成功态的 1/3，veil 去饱和；`fail` 音已在失败流里响过，**这里不再发声**。落定 = 点牌，牌面只有一道细青线填满，**没有压印**——失败不盖章。

### 6.7 跳过、简版与中断

- **点按跳过**：召唤到揭示之间任意点按 → 直接落「可选」终态（全部翻面、领位已抬），只响一声 `tap`。
- **同日简版**：同一天第二次起，发牌与揭示合并——牌直接正面落位（240ms）。
- **切后台 / 来电**：计时暂停；回来直接落「可选」终态，不重播。
- **杀进程**：回来 150ms 淡入恢复到「可选」，不重播、不重发（呈现层健壮性，不引入任何持久化规则）。

## 7 · 手势语法

### 7.1 手势表

| 手势 | 在哪 | 结果 | 永远不会 |
|---|---|---|---|
| 点侧牌 | 所有牌阵 | 送到领位（`rung` + 8ms 震） | 落定 |
| 左右滑 | 扇 / 台 / 轨 | 换领位；甩动超阈值翻一格；两端橡皮筋 | 落定 |
| 长按（≥350ms 且不动） | 牌的上半张 | 审视；松手回位 | 落定 |
| 点领位 | 所有牌阵 | 落定 | — |
| 点出口铭牌 / 返回键 | 有出口的牌桌 | 收牌（= 等会儿 / 算了，现有语义） | — |

长按只做一件事——**审视**。落定永远是点一下，不需要按着不放。

### 7.2 防误触五条

1. **侧牌永不落定**——所有牌阵统一，无例外。
2. 揭示完成前整桌断命中，只留「点按跳过」。
3. 落定瞬间锁桌：一下 = 一声 + 一震。
4. 收起 / 隐藏的牌桌一律 `IgnorePointer`（本仓库踩过「看不见的按钮替派单板挨点」）。
5. 手指位移 > 8px 判为滑动，不再触发点按。

### 8.2 台词节流

### 8.3 牌面批注的来源

### 8.4 视线跟随（可选增强，不是依赖）

## 10 · 视觉细节规范

### 10.1 真源口径（B 系）

`tokens.dart`：底 `C.voidBg #03060E` / `C.abyss` / `C.navy`；主色 `C.blue #38E1FF`；文字 `C.ice / C.mist / C.dim`；描边 `C.line`（α.26）/ `C.line2`（α.12）；稀有度 `C.rF ~ C.rS`。字体 **ShuHei**（标题）/ **FangYuan**（正文与她的话）/ **Tektur**（数字）/ **KodeMono**（系统读数）——全是可变字体，字重必须写 fontVariations。缓动 `kOut = Cubic(.16,1,.3,1)`；弹簧真源 `Spring(k:120, ζ:.9)`（23 号明令禁换 Flutter `SpringSimulation`）。AGENTS.md 里的 Rajdhani / `#0A0E1A` / stiffness 100 是 A 系归档口径，两套口径并存的事实见 25 §1，**本文一律按 B 系**。

### 10.2 牌框材质

- 底：`C.navy` α.86 + 背景模糊 12（「全息描边」关时改 α.94 纯色）；
- 描边 1px `C.line`；领位升 `C.blue` α.6 + 外辉 blur 22；
- 圆角 12；斜切 12px 统一在**右上**（残局牌改左下——「倒过来的牌」）；
- **光源全局左上**：牌面左上内沿一条 1px 高光（α.15），压印投影向右下偏 2px——所有牌被同一盏灯照着；
- 扫描线只出现在牌背与 S 级牌面。

### 10.3 稀有度纪律与辉光预算

稀有度色只在三处：左侧 3px 竖条 + 印位字母 + 预辉（§4.4）。天赋 / 称号 / 设置**不分稀有度**，要分档就用 1~3 道青色内框（Ⅰ / Ⅱ / Ⅲ）。**同一时刻只有领位发光**；S 级全息箔计为辉光，S 级领位不另叠外辉。

### 10.4 与「禁三等分卡列」的兼容

扇阵静止时**不是**三张等大平排：领位 1.0 抬起、侧位 .82 下沉外倾——层级本身就是答案，不违禁则。

### 10.5 字体纪律

数字永远 Tektur（禁正文字体排数字）；KodeMono 只做角标 / 编号 / 计数等系统读数；禁 emoji、禁 Inter / 衬线；中文标题 ShuHei、正文与她的话 FangYuan。
