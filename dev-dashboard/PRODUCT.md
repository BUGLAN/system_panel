# 宿主 SYSTEM —— 把"我想变强"变成每天有人盯着你做完的手机 App

## 项目简介
这是一个自我提升 App，但打开它看到的不是待办清单，而是一个住在手机里的"系统"。

她是网文里那种金手指：给你派任务、看你交的证据、当场结算，做得好给你加属性和金币，做不好就毒舌你一句。你是"宿主"，任务只有她能发，你负责去做、回来交截图。每天最多 6 单，一天一天攒出等级、连击和六维成长。她还会记事——你跟她说过的话她记得，能替你查进度、换任务、调整计划。

给谁用：想变强但自己坚持不下来、又吃"被系统绑定"这套叙事的人。她存在的意义是让自律这件事有观众、有回音、有代价——做完有人结算，没做完有人记得。

## 当前方向
- 阶段: 主线功能已跑通——绑定、派单、接单、交证据、结算、失败补救、回顾、对话整条链都能用；剩下的是打磨手感与补结构性缺口
- 方向: 把"她主动找你"这条补上（提醒），再收拾结算/发布的演出时长（要你先定），让日常回路从"打开才有"变成"她一直在"
- 下一步: 你先拍 D6（演出时长按哪份规格）和 D1（WebView 这么用下去算不算定案）；这两件定了，动效收尾与真机验证就能排上

## 使用流程
1. 第一次打开 :: 不是首页也不是注册页，是开机自检：她闭着眼悬在舱里，日志一行行滚出来（"校准良心……未找到，跳过"），你碰一下屏幕她才睁眼 :: 证据: prototype/opus-v2-dir/index.html, app/lib/screens/boot_screen.dart
2. 报名绑定 :: 她问你叫什么、想变成什么样；"我想变优秀"这种话会被当场驳回，必须给一句能拆开的目标；接着几张卡问清细节，问完当场把目标拆成环 :: 证据: prototype/opus-v2-dir/js/flows.js, app/lib/widgets/interview_deck.dart, app/lib/state/goal_gen.dart
3. 领任务 :: 底栏点"委托"，一块全息玻璃板砸下来，右上角骰子滚出稀有度，她当着你的面用激光把字一行行刻上去；板上的报酬就是结算要给的那个数 :: 证据: app/lib/widgets/plate.dart, app/lib/state/quest_flow.dart
4. 接下它 :: 不是点按钮，是把手指按在指纹上 0.9 秒不回弹；中途松手会被她抓包「……犹豫了？」 :: 证据: app/lib/widgets/hold_button.dart
5. 去做，回来交证据 :: 计时器开始走，最多交 3 张截图；她真的会看一眼照片判"像不像"，判不了也照收；证据越多暴击率越高，也能用道具保底或翻倍 :: 证据: app/lib/widgets/exec_panel.dart, app/lib/agent/vision.dart
6. 结算 :: 扫描线从证据上过一遍，一个巨大的 EXP 数字砸进屏幕，经验条当场涨；命中暴击盖上 CRIT 印章。整个过程你只需要看着 :: 证据: app/lib/widgets/result_panel.dart, app/lib/data/rewards.dart
7. 撑不住可以认输 :: 按住 1.2 秒，画面变暗、变安静、字幕更短，但补救单已经摆在同一块板上——"永远有补救"是机制，也是她的底线 :: 证据: app/lib/widgets/fail_layer.dart
8. 主线走到底 :: 最后那一环收下时她不收工，当场让你立下一条新主线，按你说的时长重铸 5~8 环——路不会断，只是换了方向 :: 证据: app/lib/state/goal_gen.dart, app/lib/state/quest_flow.dart
9. 看自己长成什么样 :: "面板"页是你的档案（六维雷达、称号、装备、战绩）和「近 7 天」回顾卡；"主线"页是围在她身上的一圈圈环，点任一环看要求 :: 证据: app/lib/widgets/radar.dart, app/lib/widgets/stats_pane.dart, app/lib/widgets/sheet.dart
10. 随时找她说话 :: 首页直接打字跟她聊，她记得你之前说的，也能替你查状态、换任务、调整计划；不填 API Key 也能点快捷钮 :: 证据: app/lib/chat/chat_panel.dart, app/lib/agent/tools.dart, app/lib/agent/memory.dart
