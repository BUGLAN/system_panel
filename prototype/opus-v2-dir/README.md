# 宿主 SYSTEM · 重做稿（opus-v2-dir）

一个能打开、能点、能看完所有时刻的**移动端原型**。不是概念图，不是提案。
浏览器里的 390×844 手机，里面住着一个系统。

---

## 跑起来

```bash
cd prototype/opus-v2-dir
node server.mjs          # → http://localhost:4925
```

终端会同时打印一行**局域网地址**——手机连同一个 Wi-Fi 直接开那个地址，就是真机手感（Live2D 模型必须走 http，`file://` 读不到 moc3，所以必须挂这个服务，不能双击 index.html）。

桌面上右下角有 **演示控制台**（只在桌面出现，手机上没有）：换存档、直接看派单/结算/失败、快进时间。想一口气看完所有时刻用它；想按真实节奏走，就从头开始。

第一次启动 ≈ 1.8 秒（模型下载 + 编译），之后触碰屏幕才唤醒。

## 我怎么想的

**她不是这个 App 的一部分，App 是她的一部分。**
所以整个屏幕只有一层结构：**舞台**（她在中间，脚下有环、头顶有光）+ **围绕她转的轨道**（HUD、字幕、底栏、所有面板都从边缘浮出来）。没有一个"内容区"把页面切成上下两半——那样她是页面里的插图，不是这里的主人。所有面板都是**从屏幕边缘滑出的全息板**，压在半透明的她身上，关掉就回到她。她从来不消失。

**第一秒必须是"这是个游戏"。**
打开不是 logoscreen 也不是首页，是**开机自检**：她闭着眼悬在容器里，日志一行行滚出来（"挂载人格模块……毒舌 ✓ / 校准良心……未找到，跳过"），底下写"触碰屏幕 · 唤醒系统"。你点一下，她才睁眼。第一句是「……就你？」。第二句就开始问你叫什么、想变成什么样。**没有注册页、没有引导浮层、没有"开始使用"按钮。**

**派单要有分量，但不是通缉令。**
上一版被字面执行成了西部悬赏令（黄纸、绳、血印），那表达的是"通缉"，不是"分量"。这一版的分量来自**材质与动作**：一块全息玻璃**砸**下来落定，等级骰子在右上角滚出稀有度，然后她当着你的面**用激光把字刻上去**（一行行烧字）。接单不是点按钮——是**按住你的指纹**，0.9 秒不回弹才算数；中途松手会被她抓包（「……犹豫了？」）。**"不可划掉"是靠动作实现的，不是靠边框实现的。**

**结算要让你想截图。**
扫描线从证据上过一遍 → 一个**巨大字重的数字砸进屏幕**（EXP）→ 命中暴击时盖上 CRIT 印章和双倍卡公章 → 一行行小标签浮起来（金币 / 六维 / 连击）→ 最后她头顶的**那一环被点亮**。整个过程你只需要看着，不需要点。结算结束还给一张「保存战报」——真的能导出一张 900×1600 的 PNG。

**失败要更暗、更安静、更短——但不能羞辱人。**
认输也是**按住**（而不是点一下）。画面整体压暗、饱和度抽掉，没有冲击音，字幕比平时更慢、更短，只有一句。然后在同一块板上，她**已经给你备好了补救单**——明天此时之前做一半，这次就算划掉。「永远有补救」是机制，也是她这个角色的底线。

**电光蓝不许被盖掉。**
整个基底只有深蓝虚空 + 电光青两个颜色。暖色**只**在稀有度色谱里出现（B 金 / A 橙），而且只在那一张单子上出现——它是"信号"，不是"氛围"。她身上的颜色被全息滤镜统一过色相，不会跳出暖调。没有渐变霓虹、没有毛玻璃泛滥、没有一根多余的装饰线。

**主线不是进度条，是天花板。**
这是我最花力气的地方，见下。

## 我最喜欢的一处：主线环是**围在她身上**的

主线 5~8 环，我没有把它做成页面里的一条进度条，而是**把环套在她身上**——从脚下 R1 一直到头顶的最终环（"三个月跑完半马"那个字就悬在她头顶上方）。每一环是一圈绕着她的椭圆光轨：

- **已走过**：实心发光的环 + 刻度
- **脚下这一环**：一颗彗星沿着环慢慢扫，永远不停
- **还没到**：虚线暗轨，悬在那里

环的前半圈画在她身后、后半圈画在她身前——所以她是**站在环里面**的，不是贴在一张图上。完成一环，那一圈真的亮起来；主线走完的一刻，**所有环同时亮起，从脚下一路亮到头顶**。

理由：这个产品所有抽象的东西——进度、目标、等级——最容易变成仪表盘。而这套环把「目标」变成了一个**空间关系**：它离她的头顶有多少，你一眼就知道。它不是"数据可视化"，是**她的一部分**。她说话时环跟着呼吸，她打瞌睡时环变慢——你不会觉得在看一个进度条，你会觉得**你离她还有多远，是看得见的**。

（第二喜欢的是那个指纹：接单是一次**身体的承诺**。0.9 秒的按住，是这一版里唯一一件"你需要付出一点点力气才能做到"的事——这正是"分量"的来源。）

## 有什么

| 时刻 | 在哪 |
|---|---|
| 开机 / 唤醒 | 打开就有，点屏幕 |
| 绑定仪式 | 首次进入：报名、立目标（一句梦话会被当场驳回）、拆环、见面礼 |
| 派单 | 底栏中央「委托」→ 玻璃板砸落 → 刻字 → 按住指纹接单 |
| 执行 | 计时、证据槽（真能选图，会压成缩略图）、暴击率、道具、按住认输 |
| 结算 | 扫描 → 砸数字 → 暴击/双倍印章 → 经验条 → 环亮 → 保存战报 |
| 失败 / 补救 | 按住认输 → 暗场 → 补救单已经摆在板上 |
| 主线 | 底栏「主线」→ 环全景，点任一环看要求 |
| 档案 | 六维雷达（平方根刻度）、称号、EQUIP、战绩 |
| 补给 | 四种道具，金币唯一去处 |
| 系统 | 音效 / 她的声音（电子音节·人声·静音）/ 震动 / 全息描边 / 重置 |
| 结局长 | 最后一环完成 → 整轨亮起 → 主线达成 |

**技术**：自写 WebGL2 渲染管线（`ournotes-live2d` 自定义元素 + Live2D Cubism Core，模型 = 丰川祥子 casual_spring，**63 个动作 / 28 个表情**，全部由模型自带资源驱动）；**镜头是自己算的**——每帧在播放器的投影矩阵右边乘一个世界空间仿射，把「世界里的某一点」钉到「手机屏上的某一点」，所以八个时刻各有自己的取景（开机待机是远景、派单怼脸、执行退到右侧）；情绪不是贴纸，是**参数级**的：头/身角度、眼睑、眼笑、眉（只在动作算出的眉形上叠偏移，绝不写绝对值）、嘴型包络、脸红、呼吸，再加一条后置覆写钩子在「模型算完、渲染之前」补写；主线环是画在世界空间里的椭圆投影到一张 2D 画布上，加色混合盖在模型前面；自写全息滤镜（边缘光 + 扫描线 + 色散）；所有音效**现场合成**（Web Audio，没有音频文件）；语音默认走浏览器的中文 TTS，拿不到就退回电子音节——三条路都在设置里能切。

**没做的事**（按你的硬要求）：没有聊天界面（她说，你按钮回答；只有"名字/目标"两处需要打字，那是**输入**不是**对话**）；没有待办清单；没有仪表盘；没有暖色盖过电光蓝。

**存档**：`localStorage`，只有这台设备。浏览器清数据 = 宿主换代。

**模型与许可**：她用的是**丰川祥子**（BanG Dream! Our Notes 游戏数据原样包 `adv_live2d_sakiko_010_casual_spring_01`），
63 个动作 / 28 个表情全部来自这一份数据；播放器是 [ournotes-player](https://github.com/StarMoe-org/ournotes-player) 0.1.6
（AGPL-3.0-only + 浏览器例外，见 `vendor/ournotes-player.LICENSE*`），Cubism Core © Live2D Inc.。
**模型本体不入库**（`live2d/` 被 .gitignore 挡着，版权归 Bushiroad / Craft Egg / Ishimori），
换模型的完整说明见 `live2d/sakiko/README-source.md`——一句话：把同样的包放进 `live2d/<名字>/`，
