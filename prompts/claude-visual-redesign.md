# 宿主 SYSTEM · 视觉重做

## 这是什么

用户是**宿主**，App 是**系统**——一个毒舌但靠谱的存在。它发布任务、盯着宿主干活、结算时给奖励、失败时嘲讽两句，但永远留一条补救的路。

核心循环：**系统发布任务 → 宿主去现实里做 → 截图证明 → 系统结算 → 宿主变强。**

任务有稀有度，从 **F 到 S**——做任务像捡装备。奖励分三种：经验、金币、**六维属性**（力量 / 敏捷 / 体质 / 智力 / 感知 / 魅力）。目标拆成一条 5~8 环的**主线**，一环一环往前走。有连击、有称号、有暴击、有免死金牌、有双倍卡。失败不惩罚身体，只惩罚自尊——系统会念出你真实的连败数据。

这层"系统流"的味道，是这个产品的命。

## 我要什么

不是"精致"。是**上瘾**。

> 下面每条都是**判断标准**（用户会有什么反应），不是让你照着造句的比喻。
> 别去画"悬赏令""开箱""主菜单""副本"这些东西——那些词只是想说明强度。

- **发布那一刻**：这个任务是冲着他来的、有分量、不能随手划掉
- **结算那一刻**：奖励被"给"出来的一秒要有惊喜——数值往上跳、稀有度色炸开、系统甩你一句毒舌。要爽
- **打开的一瞬间**：不像打开了一个待办清单，像进到了另一个地方
- **执行中**：有"我正在被计时"的紧张，也有"我在变强"的证据感
- **失败**：更短、更暗、更安静。不吵闹，但让人难受

一句话：**它得让人愿意再打开一次。**

## 完全自由

色板、字体、布局、结构、组件、动效、交互——**全部由你定。没有参考，没有既有设计要遵循，没有需要兼容的东西。**

你不需要在什么基础上"改"，从零开始画。

唯一保留的一条：这是**手机 App**。

## 交付

- 能打开、能点的东西。**不是设计稿，不是文字方案，不是概念图。**
- 不要改动仓库里已有的任何原型——这是你的新作品，放在 `prototype/opus-dir/`。
- 附带一段话：**你怎么想的，最喜欢哪一处。**
