全部落在「沿某条边数 1~7 个记号」这一根轴上，只是记号形状换了：

**先给一条贯穿十条的量化判据（后面反复用到）**：领位卡面顶色 `#16294A` 的 CIE L\* = **16.8**，底端 `#080F1E` 的 L\* = **4.4**（sRGB→相对亮度→CIE L\* 分段公式算）。在这两个底上叠 `#000` 与 `C.ice #E9FBFF`（纸白上限 L\* = 97.4）：

| 叠加 α | 叠黑：卡面顶 ΔL\* | 叠冰白：卡面顶 ΔL\* |
|---|---|---|
| .05 | −1.0 | +4.8 |
| .10 | **−1.9** | **+9.2** |
| .20 | −3.9 | +18.1 |
| .35 | −7.0 | +30.9 |
| .55 | −11.3 | +47.1 |

→ **同一个 α，"提亮"的 L\* 增益是"压暗"的 4.5~5 倍。** 深底上做材质纹理只有一个方向：提亮（冰白 α .02~.06），或"暗底 + 一侧亮边"配对；单靠压暗要 α ≥ .25 才有可辨台阶。这一条直接判掉 #2、#10 的纹理写法（见 B2、B10），也是 #3「按住暗区 α .10」失效的原因。

### B1 · 钢印卷宗

- **死法（几何，可验算）**：稀有度「沿左下斜切边排 7 个 ø3 孔」。斜切 c=16、六层卡边内缩 10.4 后，**剩余斜边只有 √2·(16−0.5858×10.4) = 14.0px**（`docs/40` §3.2 的账），7×3 = **21px** 排不下。若改排进内容区，就成一条斜穿「规格表」的孔列（规格表在 y 123~161）。
- **死法（越界）**：三层纸各错开 1.5px，并集 = 151×223 > 148×220 的固定盒，最外层会被 `DutyClipper` 裁掉，"三层纸"只剩内侧两层，翻车点栏说的"并成一条 4px 灰边框"会提前发生。
- **红线**：无（黑缝 α .35 叠在不透明卡底上，不构成半透明）。
- **三重编码落位**：① 底缘状态线主动让位 —— 十条里唯一主动处理这条冲突的写法，值得保留；② **但"执行中＝左上金属夹"正好压在左上 = 六边印(12,12,34,38)+星轨(12,54) 上**，执行态读不出稀有度；③ **"已完成＝四角打孔穿线"压在四角 chrome L 折线与 C 起稀有度菱形上**。左上、四角、斜切三个编码位同时撞。
- **四重限制**：纸纤维 4px α .08 的密度是全套里最对的（对得上 `docs/40` 的 6px 噪点）；斜切边承载 7 孔则是几何不可行。
- **翻车点栏**：挑的是 1px 纸纹与 1.5px 错位（都是真问题），但漏掉了会先死的两处（孔排不下、左上被夹占）→ **不合格在"挑错靶"，不在"写虚"**。
- **三觉自洽**：纸 → 软 / 短 / 单点，一致；但「接单＝短干、30ms 尾」+ 触觉 `10-30-18` 与已落地的 `press`（0.53s / −11.2dBFS）不是同一量级（见 P0-10 跨条）。
- **名字**：能想象，但它与 `docs/40` §2.1 已写明的「契据·盖章」几乎同义 → 十条里差异化最低。

### B2 · 冷石凿痕

- **死法（尺寸）**：刻痕 = "2px 暗线 + 错开 2px 的 1px 亮线"，侧位 0.84 后错开 **1.68px**、亮线 **0.84px**，两项都掉到「1px 会糊、2px 才勉强」以下 → 整卡读成灰板（该条已自认，属诚实）。**未自认的第二处**：稀有度第二读法"主刻槽宽 2/3/4px"，0.84 后 **1.7 / 2.5 / 3.4px**，三档只能读出两档。
- **死法（α 方向，见 B.0 表）**：花岗岩颗粒"5px 网格 2×2 **暗**点 α .10" → ΔL\* 只有 **−1.9**（要 α .20 才到 −3.9），而 2px 见方的点缩到 0.84 侧位只剩 1.7px，观感是"屏幕脏点"不是"石材颗粒"；卡面整体读成纯色板。改法：亮颗粒（冰白 α .03~.06 才够），或"一点暗 + 一侧亮边"配对。
- **红线**：无。但"破损越多越强"（碑顶断口 1~7）在语义上是"越稀有越残破"，与全产品「稀有 = 更多工艺/更亮」的直觉相反 —— 不是红线，是语义反向。
- **三重编码落位**：断口画在顶边 = 六层卡边 L1/L2/L3 与角标 kicker(54,16,82,12) 的位置，抢位；碑额正中 6px 六边浅坑（母题落点）也落在 kicker 的 x 区间内。状态（湿痕/填漆/裂纹）全在卡内，**不与底缘线抢，这点干净**。
- **四重限制**：纯几何可行、零常驻循环、零新增色相 —— 十条里最"做得出来"的一条。
- **翻车点栏**：具体、带数字，质量合格；漏掉"三档槽宽只读出两档"与"颗粒方向做反"。
- **三觉自洽**：**矛盾一处 —— 动效性格"落定后完全静止，连回弹都不该有" vs 声音"落定＝200ms 低频闷响（带一次余震）**；听觉的余震会让静止的卡在心理上继续动，二选一。

### B3 · 活体荧光（P0 最密集的一条）

- **死法 1（红线 1）**：卡边「3px 暗青 α .35 向内分三层渐隐到 **0**」= 卡的最外 3px 与背景混合，她会在卡边渗出来。宿主三次否决过"透明度太高"，这是同一种观感；红线要的是**不透明硬边**（现状 L1 是 1px 实线）。
- **死法 2（红线 1 或性能，二选一）**：「可接＝整卡呼吸（亮度 ±12%）」—— 用 `Opacity` 做 = 卡在 0.88~1.0 之间反复变半透明，每 2.4s 把她透出来一次；用叠色/`ColorFilter` 做 = 5 张卡每帧 `saveLayer`（`docs/40` §5.4-1 明令禁止）。
- **死法 3（状态语言）**：可接 vs 执行中只差呼吸周期 2.4s vs 1.8s —— **reduce-motion 下两者同帧同像素**，五态里有 2 态不可读（`docs/40` §5.5 要求 reduce 下仍可辨）。另外"已完成/已放弃"是静态可读的，说明这条方向并非没有静态语言，是**只给了两态动效**。
- **死法 4（α）**：按住"指下凹出一块 24px 暗区 α .10" → ΔL\* 仅 −1.9，按下去基本看不到凹陷。要 α ≥ .25（约 −4.8）才成立，或改"暗区 + 上缘亮线"配对。
- **红线（另一处）**：无新色相。#3 的"湿润感来自径向渐变，不来自透明度"这句话方向是对的，但被卡边渐隐与整卡呼吸抵消了。
- **三重编码落位**：稀有度=珠（沿脉络末端）= 放弃左上；状态只靠整卡动效 = 放弃底缘；等于五态没有任何静态承载。
- **四重限制**：自认高代价 + 【可能需要 Rive】（合规）；但"降级=6 段按序点亮"已经不是同一个方向，降级版要重写画面句。
- **翻车点栏**：Lead 已补 5 循环那条；仍缺"呼吸=Opacity 即红线"与"reduce 下状态消失"两条会先死的。
- **三觉自洽**：接单"湿黏低频咕 120ms" + 触觉 `8-90-8`，与产品唯一结算点（`press` 0.53s / −11.2dBFS）不匹配；完成="600ms 下行长音"与 `docs/41` §3.8「完成用 `ding` 升调」方向相反（升=记为完成 是全产品已定的语义）。
- **名字**：能想象，但像"生化/医疗影像"品类，不像"她递来的一张委托"。

### B4 · 真空余辉

- **死法（尺寸）**：自认玻璃感全押在"6px 镀银 + 4 个 3px 焊锡管脚"；0.84 后 = **5.0px / 2.5px 见方 × 4 个**，侧位牌上就是"一条暗带 + 四个灰点"，与噪点同级。
- **死法（克制律，可验算）**：稀有度「S 档整管亮度 **+15%**」是整卡面积效应 —— 按 `docs/40` §4.2 的当量算法（颜色面积 × α），100% 面积 × .15 = **15% 当量 ≫ S 档 10% 预算**。S 档的"强"应该靠位置与结构（印/角饰/外辉），不能靠整卡提亮。
- **死法（性能）**：辉光"3~4 层同心轮廓往外扩、α 递减，**每帧重绘**" —— 必须落到 15fps + 独立 `RepaintBoundary`（`docs/40` §5.4-6/7），否则 5 张卡每帧全重绘。
- **红线**：无（明确写"卡面永不透背景"，"把透明需求转成背面镀银"是十条里最正确的一次红线处理）。
- **三重编码落位**：稀有度换成"栅极沿六边顺时针 7 段"→ 落在**中景**（校验环 + 水印的位置），抢中景；右下"金属管座压到黑 α .8"会让右下印/计时失去底色对比；**左下 45° 斜切改成 8px 平口 = 删掉归属编码**（见 P0-11）。
- **四重限制**：静态层可缓存，主要代价是辉光；电弧只是一条线位移，便宜。
- **翻车点栏**：写的是结论（"玻璃感全丢"）而不是场景，但它给了 3~6px→侧位只剩亮线+四点的量化推演，**勉强合格**；建议直接写成"侧位牌截图里，除四个 2.5px 亮点外找不到任何可辨特征"。
- **三觉自洽**：**咬合＝"叮"（1.2kHz，300ms 长尾）与 `docs/41` §3.3 直接冲突** —— 咬合是最高频的一档（每 104px 一发），必须 28ms / −33dBFS / 与 8ms 震动同一数量级；300ms 尾音会盖住下一格（最小响间隔 120ms）→ 拖动时变一片嗡。
- **名字**：像 CRT/老式示波器的余辉，不太像"一根刚通电的管子"。

### B5 · 军规开关

- **死法（尺寸，自认）**：螺丝 r=2.5（0.84→**2.1px**）+ 丝印 1px（→**0.84px** 亚像素）。多根刻度并排时，Skia 按覆盖率渲染成 30%~60% 灰 → 一片灰雾，"军规"识别度全丢。
- **死法（未自认，信息重复）**：「执行中＝指针在走」是**第二个计时器**。右下已有 Tektur 计时数字，一个会走的指针 + 一个数字读同一件事 = 两个源；且执行中是"唯一执行中"，同屏只有一个，性价比更低。
- **红线**：无。触觉/声音全部落在现有波形上，无新增色相。
- **三重编码落位**：中景=刻度盘 → 抢校验环 + 六维水印；右下=指针/管座 → 抢印/计时；左上=螺丝（安全）。**两处抢位**。
- **四重限制**：「点击瞬间＝开关 60ms 两帧硬切」是这个尺寸下最容易成立的一招（不做过冲、不做形变），方向正确。
- **翻车点栏**：具体且诚实（r=2.5、丝印 1px），质量在平均线以上。
- **三觉自洽**：金属闸门/硬止 ↔ 两声硬咔哒 ↔ `12-10-20` 一致；但**接单"啪"（快、脆、无尾）** 又把唯一结算点写成轻响（P0-10）。
- **名字**：像"产品规格 / 工业标准"（MIL-STD），像设备面板不像牌。

### B6 · 灼热烙痕

- **死法（红线 3，残留）**：卡边栏仍写「**1px 深棕黑描边**」。棕是暖色相，而同一条的「色相账」写着"不碰暖色、一律用黑 + 冰白 α" —— **自己给自己判了废**。Lead 已把其余棕色措辞删净，这一处漏了。
- **死法（α 单位不可验）**：翻车点"亮度差不到 **.06** 时皮革读成脏蓝玻璃" —— .06 没有单位。若指相对亮度 Y 差 .06，那是 L\* 差 ≈ 8 的大台阶（早已不是"读成玻璃"）；若指 α 差，等于不可见。量纲缺失 → 不可验证，需改成具体 L\* 差或具体两层叠加。
- **死法（尺寸）**：稀有度「边缘烫穿孔 1~7」是打在**六层卡边**上 —— 等于在 L1/L2/L3 的连续路径上开孔，破坏"实体卡边"的连续性（`docs/40` §3.3 的全部六层都沿同一条 `dutyPath` 画）。
- **红线（另一处，措辞）**：一句话画面"**背面能看到凹下去的烫痕**" —— 一张不透明的卡在 UI 里看不到背面；这句话在实现上只能靠半透明兑现（红线 1），或改写成"边缘切面能看到烫痕压到底"。
- **三重编码落位**：状态=皮绳（右上）→ 与右下印/计时错开，安全；稀有度=边缘孔 → 与卡边撞（同上）。
- **四重限制**：无大问题；"烟 = 2 条 1.5px 曲线"成本最低，写法诚实。
- **翻车点栏**：两条具体死法，质量合格；但它把"加棕即判废"当成外部约束，没回头清掉自己卡边栏里的"深棕黑"。
- **三觉自洽**："滋" ↔ 14ms 偏重 ↔ 烫到收回，一致；**触觉「接单＝20-30（两下，第二下重）」实际只有 1 拍**（偶数长度数组 = on/off 交替，只有 1 个 on；见 P1-2）。
- **名字**：✓。

### B7 · 断轴齿轮

- **死法（红线 3，悬空）**：材质栏「**铜。铜绿与磨亮面**」—— 全条没有任何暖色/绿色落点，也没有"色相账"栏（#6、#10 都自算了这笔）。真按铜色画 = 新增色相（红线 3）；只画冰白 + 黑 = 读作灰铁齿轮，"铜"是空承诺。**这是十条里唯一一条"材质名与允许的画法不可能同时成立、且没自认"的方向。**
- **死法（版面）**：若"齿轮外廓"真的替代矩形，148×220 的盒子里一个完整齿轮圆直径最多 148 → **圆外四角没有版面**，名称/规格表/报酬无处安放；同时命中区、`DutyClipper`、六层卡边的内缩全部要另写一套，成本栏的"中"偏乐观。
- **死法（尺寸，自认）**：齿高 5px / 齿宽 4px（0.84→4.2/3.4px）；S 档「1 个齿」在 124 宽上是孤立 4px 凸起，读作"缺角/没画完"（已自认）。
- **三重编码落位**：**稀有度=齿数 F=7…S=1（反向计数）**，与现状星轨 F=1…S=7（越多越强）以及经验弧顺时针增长全部反向 → 玩家要在两套规则间切换；轴心 r=3~6 当第二读法，但轴心在卡心 = **抢中景**。
- **四重限制**：动效可行（预画 painter + `Transform.rotate`），"成本低"的说法成立；但轮廓重写这一笔没算。
- **翻车点栏**：三条都具体（齿 <3px、反向计数读不出）；漏掉"齿轮外廓=版面无处安放"这条会先死的。
- **三觉自洽**：棘轮嗒 70ms ↔ 每格 6ms ↔ 上弦一致；**触觉「四格连成 6-6-6-10」实际是两拍不是四拍**（4 元素 = 2 个 on；见 P1-2）。
- **名字**：✓。

### B8 · 深丝织锦

- **死法 1（几何不可行）**：右缘"露出 8~10 根散丝" —— 所有卡的绘制都在 `DutyClipper` 内（`docs/40` §5.3），**画到卡外会被裁掉**；画在卡内则与右缘 L1/L2/L5 三层框线重叠，读成"边框坏了"。
- **死法 2（尺寸）**：执行中=两条贯穿全卡的 **1px** 张力线，0.84→**0.84px 亚像素**，侧位牌上"执行中"与"可接"不可分（`docs/40` §3.9 要求线型在 91px 露出的侧位仍可辨）。
- **死法 3（纹理密度）**：经线 2px + 纬线 3px + 交叉亮点，148×220 上约 74 + 73 条 1px 线 ≈ **2.7 万画布像素的线长**，是现状 864 点噪点的 **30 倍**；再与现状 6px 噪点、11px 蚀刻线三套不同频率的规则纹理叠加 → 摩尔纹（它自认"读成屏幕脏了"）。
- **红线（位置，不是面积）**：稀有度色上"经线"—— 位置违反 `docs/40` §3.11（稀有度色只进印位/星轨/角饰/铸面晕）。面积账其实能过：S = 7×220×1px = 1540px² = **4.7% ≤ 10%**。改法：只让**末 1 根**亮线着稀有度色，其余全用 `C.ice`（面积降到 0.7%，位置也回到"边缘一处"）。
- **三重编码落位**：稀有度移进织纹 = 放弃左上；状态=张力线/卷边/散丝 = 底缘空着（五态里"可接"仍是空白态）。
- **四重限制**：自认【可能需要 Rive】合规，但**落地成本写"中"与动效代价"高"打架** —— 十条里唯一没对齐的一处。
- **翻车点栏**：具体（3px 阈值、与 864 噪点叠加），质量合格。
- **三觉自洽**：丝"嘶/嘣/嚓" ↔ 3/8/6-14ms，"软"对"轻"成立；**接单 `6-14` 是 1 拍不是 2 拍**（P1-2），且 30ms"嚓"太轻（P0-10）。
- **名字**：✓（十条里最好想象的两条之一）。

### B9 · 光刻晶圆

- **死法 1（锁定基因）**：稀有度栏「六边**逆时针**外圈那道弧」。brief 锁定的母题是「点顶正六边 + 沿六边**顺时针**的弧 + 弧头亮点 + 中央晶核」（`docs/23`/`brand/build.mjs` 唯一真源）。方向反了 = 不是同一个母题，其余三条（#1 #4 #8）都写的是顺时针。
- **死法 2（自相矛盾）**：同一栏前半句"**不数格**（数格已被星轨占掉）"，后半句"配合 die 分区被点亮的**格数**作第二读法"—— 两句话互相取消。
- **死法 3（状态，栏与栏打架）**：状态栏"一条 2px 亮线从上往下扫（**1.6s 一圈**）"是第三个常驻循环，而同一份提案的翻车点③已经写"须改成扫一次就停"。且"**扫到底停在底边**" = 正好落在现状底缘 2px 状态线的位置，两个源重叠。
- **死法 4（尺寸）**：唯一静态锚点"左下断口 1px 镜面高光（α .4）"—— **1px < 2px 可见下限**，且紧贴六层卡边的 L1/L2/L3（它自认会被盖住）。
- **红线**：无新增色相（"薄膜干涉只做明度阶梯、不做彩虹"这处改动正确）。
- **三重编码落位**：稀有度改到"对准记号弧长"（卡外圈边带）→ 让出左上，方向对；状态扫描线落底缘 → 撞底缘状态线（见死法 3）。
- **四重限制**：四边各 16px 直切 + 无圆角 = 轮廓重写（新 path + 新 clipper + 新命中区 + 六层内缩要重算 4 个切口的余量），成本"中"偏乐观。
- **翻车点栏**：三条，质量高于平均；但②"被 L1/L3 盖住"没给"所以怎么避让"的判据。
- **三觉自洽**：扫描"300ms 高频细响 −30dB"是常驻态声，随 1.6s 循环反复响就违反"系统做的事才出声"与每秒 8 发上限；触觉 5 / 6-6-6 轻，与"读入"语义一致。
- **名字**：✓。

### B10 · 碑拓朱印

- **红线（本题核心）**：一句话画面「右下角盖着一方**朱砂印，红得很正**」+ 主光「**朱印是唯一的彩色点**」+ 名字含"朱" = **三处断言一个色相**。两条路都不通：
  - 朱砂（≈ #C0392B 系暖红）不在七色谱内 → **新增色相**；
  - 改用 S 档 #FF4D5E → **稀有度色用于非稀有度处**（她的私印）。
  按红线"出现即判废"的判法，**这一版判废**；但骨架（墨拓反白 + 碑额段数 + 毛边纸 + 压印）不依赖红，重写为「碑拓墨印」后可重新送审（专答见文末）。
- **死法（改写后仍在，α 方向）**："墨色不匀处用 3~4 块不规则**暗区**（α 差 .05）" —— 浓墨区本身已是 α .90 黑（L\* 1.0），在它上面再差 α .05（α .85）的 L\* 差只有 **0.5**，远低于可辨阈值，三块暗区在真机上不存在。**要反过来做**：斑驳必须来自"墨没盖住的地方"—— 薄墨处**露蓝底**（L\* 16.8）与浓墨（L\* 1.0）拉出 **ΔL\* 15.7**，不能来自"墨再黑一点"。
- **死法（对比结构）**："字是纸白" 若做满，本质仍是"深底 + 亮字"，与现状卡（深底 + 冰白字）的对比结构相同；差异只剩"墨色不匀"，而它按上一条目前不可见 → **改写后必须证明"不看颜色也能分出这是拓片"**。
- **红线（翻车点栏误读）**：翻车点②"纸白会盖过她的脸"把红线 2 误读成亮度限制（红线 2 是位置：卡只在 45%~86%）。真正的死法是**视觉重心**：一张高对比纸白卡在安全带里会成为全屏最亮块，把注意力从她脸上拉走（`docs/40` §6.1 记过这条）。改写建议给可验证判据："截图里最亮 1% 像素不得落在卡面"。
- **三重编码落位**：稀有度=碑额分段（形状，唯一读法），碑额在顶边 → 撞 L1/L2/L3 与 kicker；状态=朱印位置/渗/落款/未钤印空位/撕角 → **右下印位本来是"方印或计时"，这里让同一枚印同时当状态和装饰**，正交律允许，但必须写明"印不再承载稀有度"（它已写，✓）。
- **四重限制**：成本最低（全静态 + 一次 `Transform` 缩放），零循环，最容易先做出来。
- **三觉自洽**：盖章 90ms 闷响 80Hz ↔ 18ms 单点 ↔ 硬停，一致；**触觉「接单＝10-40（一下轻、一下沉）」实际是 1 拍**（P1-2）。
- **名字**：✓，但"朱印"三个字把做不到的颜色写进了名字本身。

## C · 最值得做的 3 条

**① #10 碑拓（必须重写为「碑拓墨印」）**
理由：十条里唯一靠**明度反转**（把卡做成"反白的纸"而不是"发光的面"）拉开差异的方向，而实现只需静态层 + 一次 `Transform` 缩放 —— 是唯一能在本轮就做完的方向；前提是"朱砂"从名字、画面句、主光句三处删净。

**② #5 军规开关**
理由：十条里唯一把「状态」从"一条线"迁到"一个位置"的方向（五态 = 五个可静态截图判读的机械位），差异化发生在**信息编码层**而不是材质层；砍掉螺丝与丝印两处小件后，剩下的拨杆/保险盖/空槽都能在 148 宽成立。

**③ #2 冷石凿痕**
理由：全部静态层、零常驻循环、零新增色相，是"做得出来"这一端的最优解；只要把"刻痕暗线+亮线"限制在名称字（17pt 大字）上，就能避开 0.84 侧位 1.7px 的死法，且"她的字"与"委托由系统发出"同构。

> 若宿主想要一条"活的"方向：#3 是唯一候选，但它同时是**最贵**且**两处踩红线**的一条，本轮不建议。

### D.2 建议改（P1，18 条）
